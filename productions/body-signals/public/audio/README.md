# أصول التعليق الصوتي

ضع ملفات `part-1.flac` و`part-2.flac` و`part-3.flac` هنا من حزمة الصوت المرفقة بالعمل. المصدر الصوتي ElevenLabs v4، صوت ALI العربي السعودي، `Hvlnv5DwiIO2CQ6oYMZ3`، بثلاثة تسجيلات فقط. الملفات محفوظة بصيغة FLAC من عينات PCM النهائية 48kHz، قناة واحدة، دون موسيقى أو مؤثرات إضافية. هذا المعرّف معرّف صوت عام، وليس مفتاح API.

الحزمة تحفظ الصوت وتوقيت الكلمات وملفات SRT. مفاتيح الخدمة وروابط التنزيل الموقعة ليست جزءًا منها.
