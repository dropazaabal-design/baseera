# جسمك يسوي كذا… ليش؟

ثلاثة أفلام عربية عمودية، تضم 12 إحساسًا جسديًا، بشخصية Stickman مفصلية متجهية، وصوت ALI العربي السعودي من ElevenLabs v4. تعاد صياغة المصدر في مجموعات مترابطة مع تمهيد مسموع ومرئي للجزء التالي. تنتهي السلسلة في الجزء الثالث. لا موسيقى.

| الجزء | الموضوع | مدة الصورة |
|---|---|---|
| 1 | الحركة والنوم | 98.233 ثانية |
| 2 | العين والسمع والقشعريرة | 105.683 ثانية |
| 3 | الحلق والمعدة والصدر | 111.933 ثانية |

الإعداد: 1080×1920، نسبة 9:16، 60fps، H.264، yuv420p، BT.709، CRF 15، صوت AAC 192k. النصوص بخطوط Alexandria وCairo المرفقة مع تراخيص SIL OFL. ألوان الموضوع: عاجي وحبر داكن وتيل وأزرق وبنفسجي، مع أحمر هادئ للدم أو علامات الانتباه. لا تعتمد السلسلة على لوحة حساب ثابتة.

## التشغيل

يتطلب Node.js متوافقًا مع `package.json`، وFFmpeg لعمليات فحص الصوت. من هذا المجلد:

```sh
npm ci
npm run check
```

ضع ملفات الصوت `part-1.flac` و`part-2.flac` و`part-3.flac` في `public/audio/`. فك حزمة الأصول المسلّمة داخل هذا المجلد؛ فهي تعيد أيضًا الخطوط ومؤثر EffectCraft وملفات الترجمة إلى مساراتها. هذه أصول مستقلة عن المستودع. لا يحتوي المستودع على مفاتيح API أو روابط تنزيل موقعة أو بيانات اعتماد.

```sh
node --require ./scripts/runtime.cjs ./node_modules/@remotion/cli/remotion-cli.js studio --no-open
npm run render:all
```

كل تشغيل للتصدير يكتب في مجلد جديد داخل `out/`. يوفر `runtime.cjs` عنوان loopback فقط عندما يفشل استعلام واجهات الشبكة في بيئة الاستضافة؛ لا يغيّر الاتصال إذا عمل الاستعلام المعتاد.

## التعديل

- التركيبات الرئيسية: `BodySignals-Part1` و`BodySignals-Part2` و`BodySignals-Part3`.
- 18 مشهدًا مسجلًا بشكل مستقل في `src/Root.tsx`، يمكن فتح كل واحد في Studio.
- مشاهد صريحة قابلة للتحرير في `src/Parts.tsx`، ومكونات المشاهد في `src/scenes/`.
- الشخصية في `src/Stickman.tsx`، والنظام البصري والتنضيد في `src/design.tsx`.
- `production/scripts.json`: النص المعتمد. `Body_Signals_Scripts.md`: النص مع مصادر التحقق. ملفات SRT منفصلة، وتوقيت الكلمات في JSON من نوع Caption.
- `src/timeline.json`: حدود المشاهد والتغيّرات داخلها، مشتقة من توقيت تفريغ الصوت، مع تقريب إلى أقرب إطار.
- `production/EDITORIAL.md`: قرارات التحرير وحدود الفحص. `production/scene-cards.json`: بطاقات بناء المشاهد. `production/audio-qa.json`: قياسات الصوت.

## EffectCraft

صُنع مؤثر التركيز في EffectCraft v0.16.0 داخل `public/signal-pulse.ecproj`. النسخة المسلّمة تستخدم 120 إطار PNG RGBA، 1080×1920، 60fps، وتظهر لمدة ثانيتين في افتتاح كل جزء. توليد التسلسل، باستخدام المسار المطلق للـCLI الذي يعيده مثبت Craft الموثّق:

```sh
mkdir -p public/fx/pulse-v1
effectcraft-cli --project public/signal-pulse.ecproj render --comp SignalPulse --out public/fx/pulse-v1/pulse.png --format png --fps 60 --channels rgba --audio off
```

التسلسل قابل لإعادة الإنتاج ولا يُحفظ في Git. إذا لم يكن موجودًا، يستخدم المشروع حلقة متجهية بسيطة ويظل مسار Remotion صالحًا. الإخراج النهائي والتوقيت والتنضيد والصوت من Remotion.

## التحقق

فُحص TypeScript، ورُوجعت عينات من تطور المشاهد عند عرض عمودي مصغر، مع تصحيح ترتيب طبقات الشخصية وإبعاد النص عن القدمين. ضُبطت شدة الصوت قرب −16 LUFS، مع قمم أقل من −4 dBTP. القياسات النهائية للملفات المصدّرة، عندما تتوفر، موجودة في `production/final-qa.json`.

توقيت الكلمات آلي، والرسوم توضيحية مبسطة. لا يعني اجتياز الفحص التقني إثبات دقة كل معلومة طبية أو خلو كل إطار من كل عيب. مصادر الحقائق والتحفظات التحريرية مرفقة؛ المحتوى تثقيف عام ولا يشخّص حالة فردية.

الفحص بـ `freezedetect` يعتمد على مقدار تغير الصورة الكلي؛ قد يوسم فترات القراءة أو حركة متجهية صغيرة بوصفها سكونًا. يحتفظ التقرير بهذه القياسات ويميّزها عن انقطاع تشغيل مثبت. تستخدم النسخة النهائية تعويض −3 dB عند توزيع التعليق الأحادي على قناتي ستيريو.
