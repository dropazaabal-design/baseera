# دليل إنتاج فيديو جديد داخل Remotion Studio

المشروع يضيف طبقة إنتاج فوق CinematicCameraEngine الموجود في PR12، دون إعادة بنائه. راجعت حالة PR12: كان قد دُمج بواسطة المالك قبل بدء هذه المهمة؛ لم أنفذ دمجًا.

## البداية

1. ضع PNG الشفافة أو SVG داخل public/scenes/my-video. اجعل طبقات المشهد متطابقة الأبعاد ومواضع الرسم. لا يلزم تغيير React أو المحرك.
2. ضع التعليق MP3 وملف SRT داخل public/projects. الترجمة تعتمد على توقيت الملف، وليست محاذاة كلام جديدة.
3. انسخ src/projects/power31.json باسم جديد. عدل name وaudio وsrt وقائمة scenes. المسارات نسبية إلى public، وليست مسارات جهازك أو روابط خارجية.
4. لكل مشهد اختر id إنجليزيًا فريدًا، title عربيًا، duration بالثواني، preset، وlayers. لكل طبقة id وsrc وdepth، واختياريًا x وy وscale وvelocity وreveal. الصور تُعرض مع الحفاظ على النسبة.
5. نفذ npm run video:prepare -- src/projects/my-video.json. يفحص الملفات والمدد والصوت، ثم يكتب current.json الذي يراقبه Studio. يوجد أيضًا out/project-props.json للاستخدام مع --props.
6. افتح Studio بالأمر npm run dev. اختر Power31-Cinematic للريل، أو Cinematic-id لمعاينة المشهد منفردًا مع الصوت والترجمة عند توقيته الصحيح.
7. نفذ npm run video:render -- src/projects/my-video.json. ينشئ مجلدًا جديدًا داخل out ويصدر MP4 بدقة 1080×1920 و60fps. يمكن تحديد REMOTION_CHROME إذا كان Chrome في مسار خاص.

## إعداد الحركة

القوالب الخمسة: slowPush تقرّب ببطء، pullBack تتراجع، panLeft تتحرك أفقيًا، driftRight تنزلق يمينًا مع تقريب، tiltReveal ترتفع لكشف عنصر أعلى الصورة. parallax من 0 إلى 2 يضبط قوة اختلاف حركة الطبقات. camera.from وcamera.to يسمحان بتجاوز x وy وzoom دون تغيير القوالب.

مثال مشهد: {"id":"opening","title":"مو كل اختيار يعني حرية","duration":8,"preset":"slowPush","parallax":1,"layers":[{"id":"bg","src":"scenes/my-video/background.png","depth":-2},{"id":"person","src":"scenes/my-video/person.png","depth":2}]}.

## ربط التوقيت بالترجمة

المدد تتجمع دون فجوات. يمكن إضافة endCue: رقم الكابشن الأخير للمشهد في ترتيب SRT بدءًا من 1؛ أمر التحضير يحسب مدة المشهد حتى نهاية ذلك الكابشن بعد مدد المشاهد السابقة. عدل المدّة يدويًا إذا احتجت أن يمتد المشهد خلال وقفة. audioOffset اختياري لقص بداية التسجيل بالثواني، ويُطرح أيضًا من توقيت الترجمة. عند استخدام endCue يُطرح audioOffset أيضًا من النهاية المحسوبة؛ يجب أن يكون SRT من التسجيل نفسه.

لا توجد موسيقى أو مسارات موسيقية في المشغّل. الصوت اختياري: احذف audio لمعاينة صامتة، واحذف srt لإخفاء الترجمة. إذا كان التسجيل أقصر من المشاهد يرفض التحضير التصدير. إذا كان أطول يُقص عند نهاية الفيديو. المشاهد منفردة تستعمل نفس المشروع داخل نافذة زمنية، فلا تعيد توقيت الترجمة يدويًا.

## التجربة والحدود

التجربة ثلاثة مشاهد متتابعة للقانون31، 44.7 ثانية: الاختيار، الضغط، ثم التحكم بالخيارات. تستعمل الرسومات المحلية الست المتاحة، والتعليق الموجود من الريل السابق؛ لم يولّد صوت جديد. تظهر عبارة لفهم التلاعب لا لممارسته.

المعاينات تُنشأ من JSON كقالب واحد مقصود، ولا يلزم تسجيل Composition جديدة يدويًا لكل مشهد. هذه إعدادات JSON وليست واجهة سحب وإفلات أو محرر طبقات بصريًا. إضافة مشروع جديد لا تمس مكونات المحرك. افحص الأقنعة والخلفيات والمناطق الآمنة بعد تغيير الرسومات؛ لا يجري فصل AI أو إصلاح فراغات تلقائي.
