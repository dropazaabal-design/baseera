# القانون 1 — دليل الإنتاج

الحالة الحالية: **نسخة مراجعة صامتة، وليست جاهزة للنشر**. لم يُولّد صوت مدفوع. ملف SRT الحالي تقديري وليس محاذاة لتسجيل.

## التشغيل

من مجلد `productions/power31-reel`:

1. نفّذ `npm ci`.
2. استخرج حزمة [Law01-Layer-Assets.zip](https://chatgpt.com/library?file_id=libfile_3f113f52c07c8191800ca1734d61d500&account_id=personal) في هذا المجلد؛ تعيد الحزمة ملفات `public/law01/originals` و`public/law01/layers` وخط Cairo. الصور الفعلية في الحزمة، ولا توجد بدائل مؤقتة في الفيديو. مواقع الصور في JSON نسبية إلى public.
3. نفّذ `node --require ./scripts/runtime.cjs node_modules/@remotion/cli/remotion-cli.js browser ensure` عند غياب Chromium.
4. افتح المعاينة: `node --require ./scripts/runtime.cjs node_modules/@remotion/cli/remotion-cli.js studio src/law01/index.ts --no-open`.
5. اختر `Law01-Visual-Review` للفيديو، أو `Law01-SHOT01` إلى `Law01-SHOT30` لمعاينة لقطة منفردة. كل المعاينات تستعمل التوقيت العام نفسه.
6. اختبر: `npm run check` ثم `node scripts/law01/test.cjs`.
7. صدّر المراجعة مع نقاط استئناف: `node --require ./scripts/runtime.cjs scripts/law01/render_review_checkpointed.mjs`. يعيد الأمر نفسه استخدام المقاطع المكتملة إذا انقطع التنفيذ، مع التحقق من بصمة المدخلات. تبدأ نسخة جديدة بـ`--version=2` ثم 3 وهكذا؛ لا يكتب فوق الفيديو المكتمل. تُصيّر نطاقات الإطارات من Composition الكامل وتُجمع دون إعادة ترميز، ثم يفحص `video_qa.py` الملف الناتج كله. يتوفر كذلك التصدير المتصل عبر `render.mjs --review`.

## ملفات الإعداد

الإعداد المحفوظ: `projects/law01-cinematic/scene-configs/Law01-Cinematic.json`. النسخة التي يستوردها Studio: `src/law01/project.json`.

تحتوي الإعدادات على FPS، الأبعاد، مسارات الصوت وSRT، اللقطات، الطبقات، مدد الإطارات، قوالب الكاميرا، keyframes، الانتقالات، حركة مجموعات الشخصيات، مواضع الترجمة، وحالة صلاحية النشر.

يستخدم الإنتاج **CinematicCameraEngine الأصلي** و`presetCamera` و`validateProject` من Workflow الموجود. أضيفت طبقة تشغيل قابلة للتهيئة في `src/law01/Production.tsx`، مع مدخل مستقل؛ لم يُعدّل المحرك أو ملفات src للمشاريع السابقة. لا يوجد مكوّن React منفصل لكل لقطة.

## تغيير الموضوع دون إعادة كتابة المحرك

انسخ إعداد المشروع تحت اسم جديد واحتفظ بنسخة القانون 1. بدّل نصوص narration وimagePath وlayers، ثم عدّل durationInFrames وstartFrame وendFrame والكاميرا ومواقع الترجمة. اجعل endFrame حصريًا وآخر إطار مرئي endFrame-1. يجب أن يبدأ كل Shot عند نهاية سابقه. حقول name والمراجع البصرية والمحتوى قابلة للتغيير من JSON.

ضع نسخة الإعداد المختارة في `src/law01/project.json` لمعاينتها عبر نفس القالب؛ يبقى إعداد القانون 1 المحفوظ في scene-configs مستقلاً. إعادة تشغيل `build_project.py` تخص المخطط الحالي للقانون 1 فقط؛ لموضوع جديد عدّل مخطط التوجيه أو استخدم JSON جديدًا جاهزًا.

## الطبقات والحركة

كل PNG مشتق يحتفظ بقياس 936×1664 ومحاذاة اللوحة الأصلية. العمق يأتي من LayerConfig مع تعويض scale عند السكون؛ الحركة تستعمل frame-driven keyframes من المحرك. ملفات alignment.json تصف المسارات وAlpha والعمق والبصمات.

اللقطات متعددة الطبقات تستعمل أقنعة يدوية وGrabCut وإكمالًا محليًا للمناطق المخفية. هذه معالجة 2.5D محدودة وليست إعادة بناء 3D أو فصلًا عصبيًا عامًا. بعض الرسومات بقيت مسطّحة لأن الفصل المحلي لم يحفظ الزي أو التداخل بجودة كافية. حركات العين ليست دليلًا على وجود Parallax؛ يُذكر نمط كل لقطة صراحة في manifest.

حركة الشخصيات تتضمن ميل الجسم ككتلة مرسومة، تغيّر اتجاه العين، وقطعًا إلى الوضعيات البديلة المعتمدة. لم تُختلق مفاصل أو دورة مشي مفصلية. حركات الملك تفسير إخراجي ولا توثّق شعورًا تاريخيًا بعينه.

## إضافة الصوت النهائي

ضع تسجيلًا مصرحًا باستخدامه في public. أنشئ SRT وCaption JSON من التسجيل الحقيقي، ثم استبدل توقيت اللقطات اعتمادًا عليه. لا تعتمد التوقيت التقديري الحالي كدليل محاذاة. احفظ النص المعتمد كما هو إلا تصحيحًا لغويًا موثقًا.

حدّث audio وsrt وcaptions وtimingBasis إلى `recording`، واجعل approval.narration وapproval.captionAlignment صحيحتين بعد الاعتماد والفحص. افحص الصوت فعليًا: -16 LUFS، وTrue Peak لا يتجاوز -4 dBTP، دون clipping أو صمت غير مقصود. بعد اكتمال هذه الشروط فقط اجعل publicationReady صحيحًا؛ يظهر Composition النهائي ويعمل `render.mjs --final`.

لا تُضف موسيقى. لا تُستعمل ElevenLabs أو MotionLab تلقائيًا. مجرد اتصال المزود لا يجيز الإنفاق.

## التحقق

- `validate_assets.py`: فك PNG كامل وCRC وSHA-256 والأبعاد وحفظ الأصل.
- `prepare_layers.py`: فصل محلي قابل لإعادة الإنتاج، وتخزين PNG ذري مع فحص كامل.
- `test.cjs`: فحص جميع إطارات الكاميرا، الحدود، الفصل بين الأعماق، التوقيت، وSRT/JSON وبوابة النشر.
- `render_review_frames.mjs`: إطارات فعلية لبداية ووسط ونهاية اللقطات والانتقالات.
- `determinism_regression.mjs`: تصيير متكرر ومقارنة عينات من المشروعين السابقين.
- `video_qa.py`: فتح MP4 وفكّه كاملًا وفحص metadata والسواد والتجمّد.

التبعيات المحلية: Node وفق package.json وFFmpeg/ffprobe وPython مع Pillow وNumPy. إعادة فصل الطبقات اختياري وتحتاج OpenCV؛ حزمة الأصول تتضمن الطبقات الجاهزة. لا تتطلب المعاينة أو التصيير إعادة الفصل أو توليد أي صورة.

اختبار الرجوع للمشاريع السابقة عيّني وليس إعادة تصيير كاملة لكل الأفلام. الصوت السابق معطل في عينة Workflow عند غياب الأصل الصوتي. تقرير QA يبيّن حدود الاختبار والبوابات غير المكتملة.
