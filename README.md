# بصيرة — استوديو التصميم العربي

مساعد تصميم عربي لصانع المحتوى: منشور مفرد، أو كاروسيل، أو ستوري وريلز بمقاس 9:16، بالعربية من اليمين إلى اليسار. يخطّط المساعد (Claude أو غيره) الفكرة البصرية ويكتب النص ويرسم الأصول الجديدة. ثم يركّب **الاستوديو** الصفحات من عناصر مستقلة قابلة للتحرير، ويعيد توزيع المحتوى دون أن يصغّر الخط تحت حد القراءة، ويفحص كل كلمة. ويسلّم ملف محرّر يعمل دون إنترنت، أو تصميمًا في Canva. ويحفظ ما يستحق إعادة الاستخدام في مكتبة تصاميم وأصول، ويتذكّر ذوق صانع المحتوى وهويّاته.

المحرّر الكلاسيكي القائم على القوالب ما زال كما هو (المقاسات الثلاثة، وPNG وZIP وPDF لينكدإن، وفيديو الريلز، والوضع المؤسسي)، ويفتح أي كاروسيل قديم في الاستوديو بزر «فتح في الاستوديو».

## الاستوديو: كيف يعمل

```
طلب ← studio intent (ماذا يُطلب) ← studio plan (الذاكرة + المكتبة + الكاش ← المسار)
   ← نص (من الكاش أو يكتبه المساعد) + أصول (من المكتبة أو يولّدها المساعد)
   ← studio compose (تكوين + إعادة توزيع + بوابة جودة + حفظ في المكتبة)
   ← تسليم (ملف HTML أو Canva) ← ملاحظات صانع المحتوى (studio feedback) ← ذاكرة ومكتبة أدق
```

- **المسار** (`lib/studio/router.js`): يقرر قبل أي استدعاء للذكاء الاصطناعي. **إعادة استخدام** حين يناسب تصميمٌ في المكتبة المعنى والمقاس والكثافة والذوق. **توليد جزئي** حين يناسب التوزيع لكن بعض الرسوم لا تحمل المعنى، فتُولَّد تلك الرسوم وحدها. **إعادة تركيب** لتوزيع قريب. **اتجاه جديد** حين لا يناسب شيء، أو حين يطلب صاحب الحساب «شيئًا جديدًا» أو «جرافيك أقوى». والطلب المطابق تمامًا يعيد التصميم المحفوظ بلا أي توليد.
- **وثيقة التصميم** (المخطط 2): صفحات من عناصر نص وصورة وشكل، لكل عنصر معرّف ثابت (`title` و`item-4-art` و`cta`…) وإطار بالبكسل وطبقة وقفل. النص المعتمد مصدر مستقل في `content`، والعناصر تُولَّد منه. وتعديلات المستخدم (موضع، حجم، لون، صورة، قفل، إخفاء، طبقة) تُحفظ في `overrides` بمعرّف العنصر، فلا تضيع عند إعادة التوزيع أو تغيير المقاس. العقود والتحقق منها في `lib/studio/contracts.js`.
- **ثمانية تكوينات**: غلاف، وقائمة (بطاقات، وعمودان، ومصوّرة برسم لكل بند)، ومنشور مفرد، ومقارنة، واقتباس، وجملة طباعية، وكولاج تحريري، وخاتمة. ولكل تكوين حدود محتوى ووسوم معنى تبحث بها المكتبة.

## مزايا المحرّر الكلاسيكي

- **خمسة قوالب**: غلاف، قائمة خطوات، اقتباس (مع صورة القائل)، قبل/بعد، خاتمة.
- **ثلاثة مقاسات**: 1080×1350 و1080×1080 و1080×1920. مقاس القصص يترك المناطق التي تغطيها واجهة إنستغرام فارغة (٢٥٠ بكسل أعلى و٣٢٠ أسفل).
- **PDF لينكدإن**: ملف واحد، صفحة لكل شريحة بمقاسها الدقيق، يعرضه لينكدإن مستندًا قابلًا للتمرير.
- **ZIP بترتيب النشر**: `01-hook.png` و`02-content.png` … و`05-cta.png`. الرقم يحفظ الترتيب في أي مستعرض ملفات، والدور يصف الصورة.
- **منشور مفرد وبنى جاهزة**: قالب «منشور مفرد» يحمل الخطّاف ← المحتوى ← الدعوة في صورة واحدة، وقائمة «بنية جاهزة» تبدأ منه أو من كاروسيل (خطّاف ← محتوى ← دعوة).
- **فيديو ريلز 9:16**: يحوّل الشرائح إلى فيديو متحرك مدته ١٤ ثانية افتراضيًا. المشهد الأول خطّاف تكتمل حركته في أقل من ثانية، ثم مشاهد المحتوى، ثم الدعوة. يُصدَّر MP4 (H.264) أو WebM داخل المتصفح.
- **الوضع المؤسسي (Agency Kit)**: هوية كحلية وزمردية إلزامية، ومنع كل الألوان الدافئة، وقفل الخط والقوالب والإضافات والهوية. تبقى النصوص والصور فقط قابلة للتعديل.
- **إضافات قابلة للتفعيل**: الترقيم وشريط التقدّم، دعوة السحب والإجراء، العلامة والهوية (شعار وصورة ومعرّف).
- **ألوان آمنة**: ست لوحات جاهزة ولوحة مخصّصة، مع فحص تباين WCAG AA يصحّح الألوان الضعيفة تلقائيًا.
- **أربعة خطوط عربية**: Cairo وTajawal وAlmarai وReadex Pro، تُستضاف ذاتيًا وتُضمَّن في الصور المصدَّرة.
- **أرقام مشرقية أو غربية** للأرقام المولّدة (العدّاد وأرقام الخطوات).
- **حفظ تلقائي** في المتصفح، وتلوين أي كلمة بوضعها بين نجمتين `*هكذا*`.

## محرّك إعادة التوزيع (الإضافة المختارة)

اخترته لأنه يعالج مباشرة أخطاء التجربة السابقة: نص ضيّق، وتكدّس، وتصغير يُفقد القراءة. حين لا يتسع المحتوى يجرّب المحرّك بالترتيب:

1. الأحجام المفضّلة، ثم تصغيرًا خفيفًا لا ينزل تحت ٨٢٪.
2. تقليص منطقة الرسم.
3. التصغير حتى **حد القراءة** فقط: العناوين ٥٦ بكسل والمتن ٣٢ بكسل على صفحة عرضها ١٠٨٠، أي نحو ١١٫٥ نقطة على شاشة هاتف.
4. توزيعًا أكثف للتكوين نفسه، كتحويل القائمة إلى عمودين أو المقارنة إلى صفّين.
5. إزالة الرسم الاختياري، إلا إذا طُلب صراحة (`keepArt`).

ويسجّل كل خطوة بالعربية، مثل «صغّرت النص إلى ٨٥٪ … وهو فوق حد القراءة». وإن لم يتسع شيء لا يصغّر أكثر: يعلّم الصفحة بأنها لا تتسع، ويقترح اختصارًا محددًا، مثل «اختصر points.2 بنحو ٢٤ حرفًا»، أو تقسيم القائمة على صفحتين.

القياس على مستويين:

- **دون متصفح** (أداة الأوامر والاختبارات ومسار Canva): أعراض محارف مُعايَرة في Chromium لكل حرف عربي في الخطوط الأربعة (`lib/studio/metrics.js`، يعيد بناءها `scripts/metrics/calibrate.mjs`). متوسط خطئها على الأسطر الكاملة نحو ٢٪، وأقصاه نحو ٧٪، مع هامش أمان ٤٪.
- **في المحرّر**: قياس فعلي من DOM، فيُعاد التوزيع على الحروف الحقيقية عند فتح الملف، وكل تعديل يُحسب عليها.

## أداة الأوامر `studio`

مضمّنة في الإضافة: `claude-plugin/skills/arabic-carousel/scripts/studio.mjs` (تحتاج Node 18 أو أحدث، ولا تحتاج تثبيت أي شيء). كل أمر يطبع JSON، والبيانات تبقى بعد إعادة التشغيل في `~/.baseera` (أو `BASEERA_HOME` أو `--home`).

```bash
studio init                                   # المخزن
studio asset seed                             # ١٣ رسمًا تمهيديًا (اتجاه أزرق تحريري، بلا نصوص)
studio brand preset kitabwbs                  # اختياري: هوية «كتاب وبس» (@kitabwbs)
studio plan "بوست مفرد 4:5 عن ست عادات للقراءة، جرافيك عالية" --brand kitabwbs
studio compose spec.json --request "…" --out design.json --html design.html
studio edit design.json "غيّر الرسم الرابع فقط"   # محلي، أو needs: asset لعنصر واحد
studio check design.json --readback readback.json
studio canva plan design.json                 # خطة أدوات Canva الحقيقية
studio ledger report                          # الاستدعاءات والكاش، دون أرقام مخترعة
studio backup studio.json / studio restore studio.json
```

صيغة `spec.json` والتكوينات وحقولها في [`references/studio-format.md`](claude-plugin/skills/arabic-carousel/references/studio-format.md)، ومثال كامل في `references/example-studio.json`.

## المكتبة والأصول والذاكرة

- **مكتبة التصاميم** (`lib/studio/library.js`): كل تصميم محفوظ كوثيقة كاملة بنسخ مرقّمة، مع عنوان كل نسخة ونتيجة فحصها. يحفظ كذلك المفاهيم والاستعارة البصرية والتكوينات والكثافة والخطوط والألوان والأصول والحالة والملاحظات المرتبطة بالعناصر والاستخدام والنسب (`remix`).
  - الحالات: «مرشّح» بعد اجتياز الفحص، و«مستخدم» بعد التسليم، و«معتمد» بكلمات صاحب الحساب فقط، و«مرفوض» ضمن سياق محدد. فالأسلوب المرفوض لموضوع ما يبقى متاحًا لغيره.
  - البحث محلي بالبيانات الوصفية ومعجم مفاهيم عربي صغير، دون embeddings. ويرتّب بملاءمة الاستعارة (لا بتشابه العنوان)، وجودة الفحص، والذوق، وكثافة المحتوى، والملاحظات، والتنويع.
  - ولا يُمرَّر للنموذج إلا ملخص أفضل ثلاثة مرشحين.
- **مخزن الأصول** (`lib/studio/assets.js`): معرّف كل أصل مشتق من بصمة SHA-256، ويُحفظ معه المقاس والشفافية والأسلوب والمصدر والحقوق والإصدار. «المرجع الملهم» لا يُدرج في أي تصميم. والملف التالف أو المفقود يُكتشف ولا يُعاد كنجاح. ورسوم SVG تحمل `data-token`، فتتلوّن بألوان الهوية دون إعادة توليد.
- **ذاكرة صانع المحتوى** (`lib/studio/memory.js`، وواجهة «ذوقي وهويتي»):
  - **الحقائق** (الحسابات، والجمهور، والنبرة، والمحاور، والأهداف) منفصلة عن **التفضيلات**. ولكل تفضيل مصدر وتاريخ ونطاق (هوية، أو منصة، أو مقاس، أو مشروع) ودرجة ثقة وأصل (صريح أو نمط).
  - الأولوية: الطلب الحالي، ثم التفضيل الصريح الأضيق نطاقًا، ثم النمط المؤكَّد.
  - السلوك إشارة ضعيفة: تكراره ٣ مرات في تصميمين أو أكثر يصنع **اقتراحًا** لا يُطبَّق إلا بعد التأكيد، والسكوت ليس موافقة.
  - **الهويات** أكبر من الألوان: ألوان بأدوار وأسماء، وخطوط، ونبرة، وأسلوب صور، وكثافة، وقيود، وأمثلة معتمدة.
  - **المشاريع** (`projects.js`) تحفظ الموجز والقرارات والنصوص والأصول والملاحظات، و`resume` يعيدها كلها.
  - **سير العمل** (`workflows.js`) تُحفظ من تصميم ناجح، وتُشغَّل بمدخلات جديدة دون نسخ محتوى المثال، وتُرفض إن احتوت أي مفتاح أو رمز دخول.
- **الكاش وسجل الاستدعاءات** (`lib/studio/budget.js`):
  - أربعة أنواع من الكاش: النص، والأصول، والتكوين، والتصدير. مفاتيحها تشمل المدخلات المؤثرة والإصدارات، ولا يُعاد إلا ما حُفظ ناجحًا وما زال صالحًا.
  - السجل يعدّ الاستدعاءات بأنواعها، وإصابات الكاش، والمدد. والتوكنز والتكلفة لا تُسجَّل إلا إذا أبلغ عنها المزوّد، وإلا تظهر «غير متاح».

## المحرّر: الاستوديو

افتح `/studio/` في الموقع، أو أي ملف HTML تسلّمه الإضافة:

- عناصر مستقلة، وسحب للتحريك، وأسهم لوحة المفاتيح، ولوحة طبقات فيها قفل وإخفاء وترتيب، وخصائص العنصر المحدد.
- **عدّل بالمحادثة**: «كبّر العنوان قليلًا»، و«غيّر الرسم الرابع فقط»، و«حوّل الخلفية إلى الأزرق من هويتي»، و«اختصر النص مع إبقاء الرسالة»، و«اقفل العنوان»، و«وزّع البنود في عمودين».
  - ما يمكن تنفيذه محليًا يُنفَّذ فورًا، ويمكن التراجع عنه.
  - ما يحتاج المساعد يعطي طلبًا دقيقًا قابلًا للنسخ.
  - الأمر الملتبس يعرض خيارات بدل التخمين.
  - أمر الرسم لا يغيّر نصًا معتمدًا أبدًا.
- تراجع وإعادة (Ctrl+Z وCtrl+Shift+Z)، وسجل نسخ في المكتبة مع استعادة.
- فحص الجودة مع «إعادة التوزيع»، و«معاينة الهاتف» بعرض ٣٩٠ نقطة.
- «ذوقي وهويتي»، مع تصدير واستيراد متوافقين مع `studio restore`.
- التصدير: PNG، وZIP بترتيب النشر، وPDF لينكدإن، وفيديو ريلز. كلها بالمقاس الدقيق، مع تضمين الخطوط.

## مسار Canva

Canva هو المحرّر، وبصيرة لا تبني بديلًا عنه: تخطّط، وتنفّذ بأدوات موصل Canva الحقيقية، ثم تقرأ ما عاد وتتحقق منه. الكود في `lib/studio/canva/`، والمهارتان `canva-arabic` و`arabic-reels`.

**سجل القدرات** (`lib/studio/canva/registry.js`): لكل قدرة (إنشاء التصميم، المقاس، الصفحات، النصوص، عائلة الخط، الصور، الأشكال، الطبقات، التجميع، الحركة، الانتقالات، مدة المشهد، الصوت، المعاينة، التصدير، الاستيراد) وعلى كل مسار: الحالة (مدعوم، جزئي، غير مدعوم، لم يُتحقق)، والأداة أو العملية الفعلية، والحدود والمتطلبات، وآخر تحقق بمصدره وتاريخه، وهل يعدّل التصميم نفسه أم ينشئ نسخة، ومستوى التحرير المتوقع، والحاجة إلى موافقة. يُقرأ من مخططات أدوات الجلسة نفسها: بلا مخططات يظهر كل شيء «لم يُتحقق» مع آخر حالة معروفة، وأي اختبار حي سُجّل على مخطط أداة تغيّر بعده يصبح «قديمًا» ويُعاد التحقق منه. جدول وقت البناء في [`capabilities.md`](claude-plugin/skills/canva-arabic/references/capabilities.md).

**المسارات:**

| المسار | من ينفّذ | النتيجة |
|---|---|---|
| الموصل | المساعد بأدوات Canva | يعدّل التصميم نفسه داخل معاملة، ولا يُحفظ إلا بموافقة صريحة على المعاينة |
| ملف أصلي `.pptx` | المستخدم يرفعه في Canva | تصميم **جديد**: نص عربي مستقل بخطه (Cairo/Tajawal) واتجاهه، وكلمة ملوّنة في run مستقل، وصور منفصلة، وأشكال متجهة أصلية. الحركة والمدد لا تُستورد (مركز مساعدة Canva) |
| Connect API | `canva_import_editable --execute true` | تصميم جديد من الملف، فقط إن وضع المستخدم رمزه في متغير البيئة `CANVA_ACCESS_TOKEN` بنفسه؛ لا يُكتب الرمز في ملف أو سجل أو نتيجة |
| يدوي | المستخدم بخطوات محددة | ما يتيحه محرّر Canva: عائلة الخط، الحركة، المؤقت، الصوت |

لا كلمات مرور في المحادثة، ولا جلسة متصفح مفترضة، ولا مسار غير رسمي، ولا انتقال لمسار آخر للالتفاف على نفاد الرصيد أو رفض الموافقة. وكل استيراد ينشئ تصميمًا جديدًا يُحفظ معرّفه مع معرّف الأصل.

**الأدوات** (خادم MCP محلي `baseera-canva` تعلنه الإضافة في `.mcp.json`، أو `node canva.mjs <tool>`):

| الأداة | ما تفعله |
|---|---|
| `canva_capabilities` | السجل لهذه الجلسة، وتسجيل نتائج الاختبار الحي |
| `canva_inspect` | قراءة تصميم: الصفحات والعناصر والنصوص، وربطها بعناصرنا، والتغييرات الخارجية، والمعاملات المفتوحة |
| `canva_build_design` | خطة بناء على الموصل (تُستأنف عند الإعادة ولا تتكرر) وملف `.pptx` دائمًا |
| `canva_apply_patch` | «كبّر العنوان»، «غيّر الخط إلى تجوال»، «حرّك…»: عمليات على عناصر Canva المعنية وحدها، بلا توليد صور، ومعاينة الصفحات المتأثرة فقط |
| `canva_import_editable` | الملف الأصلي، واستيراده عبر Connect API عند توفر الرمز |
| `canva_build_reel` | كاروسيل أو فكرة ← ريل 1080×1920 بمشاهد وخطة مدد وحركة |
| `canva_apply_motion` | يطبّق الحركة حيث يوجد مسار يدعمها، وإلا يقول ذلك صراحة مع البدائل |
| `canva_preview` | معاينة الصفحات المتأثرة فقط |
| `canva_validate_arabic` | التحقق العربي والهندسي بعد النقل، مع دفعات إصلاح |
| `canva_export` | تصدير بصيغة يعرضها `get-export-formats`، وفحص الملف المنزّل (المقاس والصفحات ومدة الفيديو) |
| `canva_record` | تسجيل ما أعاده Canva في سجل التصميم |

**الاعتمادية:** لكل تصميم سجل يحفظ المعرّفات الحقيقية وعلاقتها (إنشاء، نسخ، تغيير مقاس، استيراد)، ومفتاح بناء يمنع التكرار عند الإعادة، والملفات المرفوعة ببصمتها فلا تُرفع مرتين، والمعاملات المفتوحة وعمرها، ولقطة بعد كل كتابة متحقَّق منها تكشف أي تعديل خارجي قبل الكتابة التالية. وتُصنَّف الأخطاء: الرصيد أو الحصة توقّف، وتجاوز المعدل انتظار مرة واحدة، والرابط المنتهي يُطلب بدله، والمعاملة المنتهية تُعاد قراءتها ويُستأنف منها، وخطأ الشبكة يُعاد بأمان، ورفض التفويض أو الموافقة توقّف. ويُعرض عدد عمليات التوليد الفعلية، ولا تُختلق تكلفة أو عدد رموز.

**موصلات مختلفة** (`dialect.js`): لا تُفترض أسماء أدوات Claude. تُقرأ مخططات أدوات الجلسة فيُعرف أي أداة تؤدي كل دور وأي حقل يحمل كل قيمة. موصل Claude يحرّر بأداة واحدة `edit-design` على `locator_id` ويحفظ ويلغي بحقل `finalize`، ويقرأ ويفتح المعاملة بـ `read-design`. وموصل آخر قد يحرّر بـ `perform_editing_operations` على `element_id`، ويفتح المعاملة ويحفظها ويلغيها بأدوات منفصلة، ويقرأ المحتوى والصفحات والمعاينات بأدوات منفصلة. وتُطبَّع البادئات (`mcp__Canva__`، `canva_`) والشرطة السفلية. تُكتب الخطط بصيغة واحدة ثم تُترجم لكل موصل: الأسماء والحقول معًا. والعملية التي لا يملكها الموصل تُعلن ولا تُرسل، والحقل الذي لا مقابل له يُذكر ولا يُرسل.

**الاستيراد غير رفع الوسائط:** يُكتشف الاستيراد من أداة استيراد التصميم نفسها، لا من `create-upload-url`. إذا كان في مخططها حقل ملف (`design_file`) يُكتب استدعاء يمرّر ملف `.pptx` نفسه: مرجع الملف الذي يعطيه المضيف، أو بايتاته بترميز base64 حين يطلب الحقل ذلك. وإذا كان الحقل رابطًا عامًا فقط، كما في موصل Claude الذي يستثني صراحةً الملفات المحلية والمولّدة، فلا يُرسل مسار محلي ولا يُنشر ملف المستخدم. يُحفظ معرّف الأصل ومعرّف التصميم الجديد، ثم يُتحقق من النص وعدد الصفحات والمقاس، ومن المظهر بمعاينة كل صفحة.

**التحقق بعد النقل** (`validate.js`): كل نص حرفًا بحرف (الهمزات، التشكيل، ة/ه، ى/ي، الأرقام ونظامها، الترقيم، الكلمة المعكوسة)، وأشكال العرض ومحارف الاتجاه، وقواعد الهوية، والحجم واللون والمحاذاة، والقص والتداخل والهوامش ومناطق واجهة الريلز، والنص الذي كبر بخط Canva.

**اكتشاف حي عن الاتجاه:** يحدد Canva اتجاه الفقرة من أول حرف أو رقم فيها، فيُحاذى «3 عادات تضاعف قراءتك» و`@kitabwbs` إلى اليسار مع `start` في تصميم عربي. لذلك ترسل `canvaAlign` القيمة `end` لهذه النصوص، ويكشف التحقق أي محاذاة خاطئة ويقترح إصلاحها. ولا يعزل Canva المقاطع اللاتينية كما يفعل محرّرنا، فظهر `@kitabwbs` داخل جملة عربية بالشكل `kitabwbs@` في التصميمين المحفوظين. والآن تُضاف علامة اتجاه غير مرئية (LRM) قبل الحساب أو الوسم داخل النص العربي في Canva وملف `.pptx`، ويعدّ التحقق غيابها خطأ ويقترح `find_and_replace_text` لإصلاحه.

**المثال الحي (٢ أكتوبر ٢٠٢٦، حساب Canva المرتبط، حُفظ التصميمان بموافقة صاحب الحساب):**

- **كاروسيل** «كتاب وبس: 3 عادات تضاعف قراءتك»: ٣ صفحات 1080×1350، التصميم `DAHW3ncJTJw`، نسخة من قاعدة سابقة `DAHW0F0Y4Gk`، فعمليات التوليد **صفر**. النصوص والأشكال والرسم المرفوع عناصر مستقلة، والقراءة الراجعة طابقت **٢٨/٢٨** نصًا حرفيًا بالحجم واللون والمحاذاة.
- **«كبّر العنوان»** عدّل عنصر العنوان وحده (من 121 إلى 133 بكسل) وأبقى الرسم، دون توليد أو رفع صور. و**«غيّر الخط إلى تجوال»** أعاد «غير مدعوم عبر الموصل» مع البديلين: خطوات يدوية، وملف `.pptx` بخط Tajawal.
- **ريل** «ريل كتاب وبس: 3 عادات تضاعف قراءتك»: ٥ مشاهد 1080×1920، التصميم `DAHW35HyR5Y` من تغيير مقاس الكاروسيل (تصميم جديد، والأصل لم يتغير): خطّاف، ثلاث نقاط بأرقام كبيرة، ثم ختام. خطة كل مشهد (المدة والحركة والانتقال) محفوظة في ملاحظات صفحته، والقراءة الراجعة طابقت **٢٦/٢٦** نصًا.
- **حالة الريل:** المشاهد أُنشئت في Canva وحُفظت. الحركة لم تُطبَّق (لا عملية لها في الموصل). المدد لم تُضبط. لا صوت. لم يُصدَّر فيديو بعد.
- **بعد الحفظ:** صُدّرت الصفحات PNG من النسخة المحفوظة (كل صفحة 1080×1350 أو 1080×1920 بالضبط)، فكشف الفحص بالعين أن `@kitabwbs` داخل الجمل العربية ظهر `kitabwbs@`. أُصلح المحوّل والتحقق، وطُبّق الإصلاح في Canva وتحقّقت منه المعاينة، وينتظر موافقة جديدة على الحفظ. ملاحظة: صورة المعاينة المخزّنة في Canva بقيت قديمة بعد الحفظ، فالتحقق من النسخة المحفوظة يكون بقراءة المحتوى أو بالتصدير.

**مستوى التحرير المعلن:** «أصلي» (كل عنصر مستقل)، أو «جزئي» (النص حيّ والرسوم صورة واحدة)، أو «صورة مدمجة»، ولا يوصف الثالث أبدًا بأنه قابل للتحرير. وتحويل الصورة إلى طبقات ليس المسار الافتراضي للعربية.

## الاختبارات

`npm test` يشغّل ١١٦ اختبارًا دون مكتبات إضافية، بينها اختبارات القبول لكل الميزات الجديدة:

- **التحرير:** تعديل العنوان يغيّر عنصر النص الصحيح وحده. «غيّر الرسم الرابع» يستبدل `assetId` المقصود وحده. التراجع والإعادة يعيدان مراجع الأصول. أمر الرسم لا يغيّر نصًا، والعنصر المقفل يرفض التعديل.
- **الذاكرة:** تفضيل حساب لا ينتقل إلى حساب آخر. الطلب الحالي يتقدّم على التفضيلات. السلوك الضعيف لا يصير تفضيلًا مؤكدًا. الذاكرة والمكتبة تبقيان بعد إعادة تشغيل أداة الأوامر.
- **المكتبة والمشاريع:** الأصل التالف أو المفقود لا يعيد نجاحًا وهميًا. استئناف المشروع يعيد النص والأصول والملاحظات. Workflow محفوظ يعمل بمدخلات جديدة دون محتوى المثال، ويرفض رموز الدخول.
- **المسار والتكلفة:** أول تصميم يستعمل التوليد ويحفظ الناتج والأصول. الطلب المطابق يستفيد من الكاش دون أي استدعاء. تعديل النص المحلي لا يولّد صورًا (يُثبَت بسجل الاستدعاءات). الفكرة غير الملائمة للمكتبة تستدعي التوليد.
- **المقاس والتخطيط:** بوست 4:5 بست نقاط، وكاروسيل من سبع شرائح. عربية مختلطة بحساب لاتيني وأرقام، ومحتوى كثيف يُعاد توزيعه، ومحتوى لا يتسع يُبلَّغ عنه باختصارات محددة.
- **سلامة النص والتصدير:** «عيوبك ← عبويك» و«٢ ← ٧» يُكتشفان، وكذلك مقاس خاطئ و٧ صفحات بدل ٢. المقاس المصدَّر يطابق widthPx وheightPx.
- **Canva:** كاروسيل عربي متعدد الصفحات بخطة موصل وملف `.pptx`. «كبّر العنوان» و«غيّر الخط» دون إعادة توليد الصور (بسجل الاستدعاءات). كاروسيل ← ريل بمدد وحركة وحالة صادقة، وفحص فيديو منزّل بمدة Canva الافتراضية يكشف أن المدد لم تُضبط. نص عربي مختلط بأرقام وحساب لاتيني يكشف الهمزة والتاء المربوطة والكلمة المعكوسة والمحاذاة الخاطئة. قدرة غير مدعومة، وفشل جزئي، وتغيير خارجي يوقف الكتابة. السجل بلا مخططات «لم يُتحقق»، والاختبار الحي القديم يُعلَّم عند تغيّر المخطط. Connect API بطلبات مزيّفة، وخادم MCP عبر stdio.

**ما اختُبر وأين (أدوات Canva):**

## إضافة قالب جديد

كل قالب ملف واحد يصدّر وصفًا للقالب ومكوّن React. مثال: قالب «رقم بارز».

**١. أنشئ `templates/Stat.jsx`:**

```jsx
import FitBox from '../components/FitBox';
import RichText from '../components/RichText';
import { SafeArea } from './shared';

function Stat({ data }) {
  return (
    <SafeArea>
      <FitBox min={40} max={120}>
        <div className="text-center">
          <div className="text-(--c-accent)" style={{ fontSize: '2.4em', fontWeight: 'var(--w-black)', lineHeight: 1.1 }}>
            <RichText text={data.value} />
          </div>
          <p className="mt-[0.4em]" style={{ lineHeight: 1.6 }}>
            <RichText text={data.label} />
          </p>
        </div>
      </FitBox>
    </SafeArea>
  );
}

export default {
  id: 'stat',
  label: 'رقم بارز',
  description: 'إحصائية واحدة بخط كبير',
  fields: [
    { key: 'value', label: 'الرقم', type: 'text' },
    { key: 'label', label: 'الوصف', type: 'textarea', rows: 3 },
  ],
  defaults: { value: '87%', label: 'من القرّاء يحفظون المحتوى المفيد' },
  Component: Stat,
};
```

**٢. سجّله في `templates/index.js`:**

```js
import stat from './Stat';
export const templateList = [cover, listicle, quote, comparison, outro, stat];
```

يظهر القالب فورًا في قائمة «إضافة شريحة»، ويُولَّد محرّر حقوله تلقائيًا من `fields`.

| نوع الحقل | المحرّر | القيمة |
|---|---|---|
| `text` | سطر واحد | نص |
| `textarea` | عدة أسطر | نص (الأسطر تُحترم) |
| `list` | سطر لكل عنصر | مصفوفة نصوص (استعمل `nonEmpty()` عند العرض) |
| `number` | رقم | عدد صحيح ≥ ١ |
| `image` | رفع صورة | `null` أو رابط `data:image/…` |

يستقبل المكوّن `data` (قيم الحقول) و`ctx` الذي يحوي: `index` و`total` و`isLast` و`colors` و`numerals` و`brand`. لإخفاء شارة الحساب على قالبك أضف `hideBrandBadge: true`. لا تفترض ارتفاعًا ثابتًا: `SafeArea` و`FitBox` يتكيّفان مع المقاس النشط ومع مناطق القصص الآمنة (المتغيّرَين `--inset-top` و`--inset-bottom`).

### قواعد كتابة القوالب

1. **ضع المحتوى داخل `SafeArea` ثم `FitBox`**، وحدّد مقاسات العناصر بوحدة `em`. هكذا يكفي بحث واحد عن حجم الخط ليصغّر التكوين كلّه مع الحفاظ على نسبه.
2. **مرّر كل نص يكتبه المستخدم عبر `RichText`**، فهو الذي يعزل المقاطع اللاتينية والأرقام ويلوّن `*الكلمات*`.
3. **الألوان من المتغيّرات فقط**: `bg-(--c-surface)` و`text-(--c-muted)` أو `var(--c-accent)`. الأوزان من `var(--w-regular|bold|black)` لأن كل خط عربي يملك أوزانًا مختلفة.
4. **خصائص منطقية لا فيزيائية**: `ps-*` و`me-*` و`start-*` و`border-s-*` بدل left/right.
5. **الأيقونات الاتجاهية** (الأسهم وعلامات الاقتباس) تأخذ الخاصية `directional`.
6. **الحبوب ذات السطر الواحد** تأخذ `whitespace-nowrap`، و**صفوف `flex-wrap`** تأخذ `w-full`. سبب ذلك أن `html-to-image` ينسخ العروض المحسوبة بتقريب كسري، فقد ينكسر صف ضيّق في الصورة المصدَّرة رغم سلامته في المعاينة.

## إضافة إضافة (Plugin) جديدة

الإضافة طبقة تُرسم فوق كل الشرائح. أنشئ ملفًا في `plugins/` يصدّر:

```js
export default {
  id: 'myPlugin',
  label: 'اسم الإضافة',
  description: 'وصف قصير',
  defaults: { enabled: true /* وأي إعدادات أخرى */ },
  Overlay({ settings, ctx, template }) { /* عناصر بموضع مطلق داخل 1080×1350 */ },
  Settings({ settings, onChange }) { /* onChange({ key: value }) */ },
};
```

ثم أضفها إلى `overlayPlugins` في `plugins/index.js`. تُحفظ إعداداتها وتُدمج تلقائيًا مع المستندات المحفوظة سابقًا.

## كيف تُحلّ المشكلات التقنية الست

**١. اتصال الحروف والخطوط في التصدير.** الصور المصدَّرة تُرسم داخل SVG معزول لا يرى خطوط الصفحة، فإن لم تُضمَّن الخطوط عاد المتصفح إلى خط النظام وانفكّت الحروف أو تغيّر شكلها. الحل في `lib/exportEngine.js`: تُطلب كل الأوزان صراحةً عبر `document.fonts.load()` قبل انتظار `document.fonts.ready`، لأن مجموعات `unicode-range` لا تُحمَّل حتى تُطلب. بعدها تُضمَّن الخطوط داخل الصورة بصيغة base64، وتُخزَّن نتيجة التضمين لكل خط. والخطوط مستضافة ذاتيًا من `@fontsource`، فلا مشاكل CORS. وفي `globals.css`: تصفير `letter-spacing` إلزاميًا (التتبّع يفكّ اتصال الحروف)، و`font-synthesis: none` لمنع التسميك والإمالة المزيّفين، مع `liga` و`calt` و`optimizeLegibility`.

> تنبيه: لا تمرّر `preferredFontFormat` إلى `html-to-image` 1.11. تعبيره النمطي العام يحتفظ بحالته بين قواعد `@font-face`، فيُسقط نحو نصف الخطوط بصمت. اكتُشف هذا أثناء البناء حين ظهر الخط العريض العربي رفيعًا في الصور.

**٢. الحدّة على الشاشات عالية الدقة.** تُرسم كل شريحة دائمًا بـ `pixelRatio: 2` (ضعف المقاس، مثل 2160×2700) مهما كانت دقة جهازك، ثم تُصغَّر بتنعيم عالي الجودة إلى المقاس الأصلي، أو تبقى بالدقة المضاعفة إن اخترتها. التحجيم في المعاينة يقع على غلاف خارجي لا على الشريحة نفسها، فتبقى الصورة المصدَّرة مطابقة بكسلًا بكسل. (`quality` لا تأثير لها على PNG لأنه بلا فقد.)

**٣. Safari وiOS.** قبل كل تصدير تُطلب أوزان الخط للنص الفعلي في الشريحة عبر `document.fonts.load()`، وتُفكّ كل الصور بـ `img.decode()`، ثم ينتظر المحرّك إطارين حتى يستقر التحجيم التلقائي. تسبق الدفعةَ جولةُ إحماء غير مرئية بدقة منخفضة. وعلى WebKit وحده تُعاد كل شريحة حتى تتطابق بصمتا رسمتين متتاليتين (ثلاث إعادات كحدّ أقصى)، وتُحرَّر اللوحات الوسيطة لأن iOS يحدّ ذاكرتها.

**٤. النص المختلط (عربي + إنجليزي + أرقام).** يقسّم `lib/bidi.js` النص إلى مقاطع، ويُعرض كل مقطع يجب أن يبقى من اليسار إلى اليمين (أسماء لاتينية، أرقام، `@معرّف`، `#وسم`، روابط، بريد، هواتف، تواريخ) داخل `<bdi dir="ltr">` بخاصية `unicode-bidi: isolate`. هكذا تبقى `40%` على حالها بدل `%40`، و`+966 50 123 4567` بترتيبه الصحيح. الحالات الذهبية في `tests/bidi.test.js`.
لم يُستعمل `U+200F` (RLM): الفقرات مُعلنة `dir="rtl"` أصلًا، وRLM لا يصلح الترتيب **داخل** المقطع (مجموعات أرقام الهاتف مثلًا)، أما العزل فيصلحه. حيث يستحيل وضع عنصر HTML، كنص `<option>`، تُستعمل محارف العزل LRI/PDI (`U+2066`/`U+2069`).

**٥. التحجيم التلقائي للعناوين.** يقيس `FitBox` الفيض الفعلي ويبحث ثنائيًا عن أكبر حجم خط بين حدّين يملأ المساحة دون تجاوز، ويعيد القياس عند تغيّر النص أو الحجم أو اكتمال تحميل الخط. اختير القياس بدل عدّ الحروف لأن عرض الحروف العربية يتفاوت كثيرًا بين الخطوط وأشكال الحرف. وإن لم يتّسع النص حتى بأصغر حجم مقروء، فلا يُصغَّر أكثر، بل يُنبَّه المستخدم في اللوحة والمصغّرات.

**٦. انعكاس التخطيط والأيقونات.** تُستعمل الخصائص المنطقية (`start` و`end` و`ps` و`me` و`border-s`) و`gap` في كل مكان، والأيقونات الاتجاهية تنعكس عبر `rtl:-scale-x-100`. ولم يُستعمل `rtl:flex-row-reverse` عمدًا: تحت `dir="rtl"` يجري `flex-row` من اليمين أصلًا، فعكسه يعيده إلى ترتيب اليسار. وكذلك `space-x-reverse` غير لازم مع `gap`.

## إضافة Claude: `arabic-carousel`

مجلد [`claude-plugin/`](claude-plugin) إضافة Claude جاهزة. تطلب من Claude «اعمل لي كاروسيل عن…»، فيكتب نصوص الشرائح ويسلّمك **ملف HTML واحدًا** فيه المحرّر كاملًا، معبّأً بالمحتوى وجاهزًا للتعديل والتصدير. الملف يعمل دون إنترنت، لأن الخطوط والمكتبات مضمّنة داخله.

**التثبيت في Claude (الويب أو التطبيق):** حمّل `arabic-carousel-plugin.zip` وارفعه من صفحة الإضافات. لإنتاج الملف بنفسك:

```bash
npm run build:plugin   # → dist/arabic-carousel-plugin.zip
```

**التثبيت في ChatGPT وCodex:** الملف نفسه يعمل هناك أيضًا. فيه `plugin.json` في الجذر بصيغة Agent Plugins المحايدة التي يقرؤها ChatGPT وCodex، و`.claude-plugin/plugin.json` الذي يقرؤه Claude، وكلاهما يشير إلى المهارة نفسها في `skills/`. يُنتج `npm run build:plugin` ملفًا مخصّصًا لـ ChatGPT هو `dist/arabic-carousel-chatgpt.zip`، وفيه ما تطلبه OpenAI فقط. ارفعه من «Upload plugin» في ChatGPT على الويب. يتطلّب ذلك، حسب OpenAI، صلاحية رفع الإضافات أو أن تكون مالك مساحة العمل أو مديرها. اسم العرض والوصف القصير محدودان بـ ٣٠ حرفًا لكل منهما، وتتحقق الاختبارات من هذه الحدود.

**التثبيت في Claude Code:** المستودع نفسه سوق إضافات:

```
/plugin marketplace add dropazaabal-design/baseera
/plugin install arabic-carousel@baseera
```

**أدوات Canva حسب المنصة:**

| المنصة | الحزمة | ربط الأدوات | ما اختُبر |
|---|---|---|---|
| Claude Code | `arabic-carousel-plugin.zip` أو `/plugin install` | خادم MCP محلي (`baseera-canva`) تعلنه `.mcp.json` ويشغّله Claude Code | ٢ أكتوبر ٢٠٢٦، Claude Code 2.1.287، إعدادات معزولة: التحقق من الإضافة، والتثبيت، و`claude mcp list` يذكر الخادم متصلًا، وجلسة عبر المضيف عرضت الأدوات الإحدى عشرة واستدعت `canva_capabilities` |
| تطبيقات Claude (رفع الإضافة) | الحزمة نفسها | المهارات؛ تشغيل خادم MCP محلي هناك لم يُختبر | لم يُختبر |
| ChatGPT وCodex | `arabic-carousel-chatgpt.zip` | المهارات وأداة الأوامر فقط: صيغة `plugin.json` لا تعرّف خوادم MCP، فلا `.mcp.json` ولا ملف خادم في الحزمة | محتوى الحزمة، وتشغيل أداة الأوامر من نسخة منها؛ لم يُختبر داخل ChatGPT أو Codex |

تعلن إضافة Claude في `.mcp.json` خادم MCP محليًا اسمه `baseera-canva` يعمل بـ Node، ويعرض أدوات `canva_*` الإحدى عشرة. وهي أيضًا أداة أوامر: `node skills/canva-arabic/scripts/canva.mjs <tool>`. الخادم لا يتصل بـ Canva بنفسه إلا عبر Connect API حين يتوفر رمز؛ أما العمل في التصميم فتنفّذه أدوات موصل Canva المرتبط بحسابك، وتتحقق منه أدوات الخادم. ولمسار Connect API الاختياري ضع رمز وصولك في متغير البيئة `CANVA_ACCESS_TOKEN` قبل تشغيل Claude Code؛ يمرّره `.mcp.json` بالإشارة إلى المتغير لا بقيمته، ولا تكتبه الأدوات في أي ملف أو سجل أو نتيجة. وملف ChatGPT لا يحمل `.mcp.json`.

**كيف تعمل (منذ 1.2):** المهارة الرئيسية `arabic-carousel` مديرة تصميم تعمل عبر أداة الأوامر `scripts/studio.mjs`: تخطّط بالمسار والذاكرة والمكتبة، وتكتب وترسم ما يلزم فقط، وتركّب الوثيقة وتفحصها، ثم تسلّم ملف المحرّر (الذي يفتح في الاستوديو) أو تصميم Canva. معها ثلاث مهارات: `canva-arabic` و`arabic-proofing` و`creator-memory`. المسار الكلاسيكي التالي يبقى احتياطيًا حين لا يتوفر Node.

**المسار الكلاسيكي:** تكتب المهارة محتوى الكاروسيل بصيغة JSON. بعدها يتحقق السكربت `build_carousel.py` من الحقول والأنواع، وينبّه إلى أخطاء الكتابة العربية (الترقيم اللاتيني، والتطويل، ومحارف الاتجاه)، ثم يحقن المحتوى في `assets/carousel.html`. هذا الملف هو المحرّر نفسه مبنيًا من كود المستودع، فلا توجد نسخة ثانية من القوالب تحتاج مزامنة.

بعد أي تعديل على القوالب أو الإضافات أو الخطوط أو الأنماط، شغّل `npm run build:plugin` وأودع النتيجة. فحص CI في كل PR يرفض أي ملفات إضافة قديمة.

## محرّك فيديو الريلز

**ارسم مرة، ركّب مرات.** لا يعيد المحرّك رسم النص العربي على اللوحة في كل إطار بـ `fillText`، فذلك يتجاوز العزل الاتجاهي والتحجيم التلقائي وأوزان الخطوط. بدلًا من ذلك، تُرسم كل شريحة بمقاس القصة خارج الشاشة بالمحرّك نفسه الذي يصدّر PNG. منها تُلتقط صورة خلفية تخفي العناصر المتحركة، ثم صورة شفافة لكل عنصر يحمل `data-anim` (`rise` أو `fade` أو `pop`). كل إطار بعد ذلك تركيب لهذه الصور فقط (شفافية وإزاحة وتكبير)، فيبقى اتصال الحروف وترتيب النص المختلط مطابقًا للمعاينة في كل إطار. والعناصر تتحرك كاملة، لا حرفًا حرفًا، لأن الحرف العربي يتصل بجاره.

**التوقيت** (`lib/timeline.js`): ١٤ ثانية افتراضيًا. الخطّاف ثانيتان تكتمل حركته في أقل من ثانية، مع تقريب سريع عند كل قطع. الدعوة ٢٫٥ ثانية، ومشاهد المحتوى تتقاسم الباقي بنسبة زمن قراءتها. تدخل العناصر متتابعة خلال أول ٤٠٪ من مشهدها، وينبّه المحرّر حين يكون نص المشهد أطول من زمن ظهوره.

**الترميز** (`lib/video.js`): المسار الأساسي هو WebCodecs عبر `mediabunny` بطوابع زمنية صريحة، فيخرج الفيديو بطول الثواني المطلوبة بالضبط مهما كان الجهاز بطيئًا، وأسرع من الزمن الحقيقي. يُجرَّب MP4/H.264 أولًا، ثم WebM/VP9 حيث لا يتوفر مرمّز H.264. المتصفحات بلا WebCodecs تستعمل `MediaRecorder` في الزمن الحقيقي. أثناء التجهيز والترميز تظهر نسبة التقدم إطارًا بإطار مع زر إلغاء، ويطلب المتصفح تأكيدًا قبل إغلاق الصفحة.

لإضافة حركة إلى قالب جديد، ضع `data-anim` على العناصر التي تريدها. لا تضعها متداخلة، ولا على عنصر يحمل `transform`.

## الوضع المؤسسي (Agency Kit)

السياسة كلها في `plugins/agencyKit.js`: اللوحات المسموحة، والخط، والإضافات الإلزامية. تُطبَّق فوق اختيارات المستخدم وقت العرض ولا تحلّ محلّها، فإيقاف الوضع يعيد تصميمه كما كان. تُعطَّل اللوحات غير المسموحة مع ذكر السبب («ألوان دافئة» أو «خارج الهوية»)، ويُقفل الباقي عبر `<fieldset disabled>` الذي يعطّل كل عنصر داخله.

مفتاح التبديل وحده لا يكفي حوكمةً، لأن أي مستخدم يستطيع إيقافه. لذلك تقفل الجهة ملفها بإضافة `"governance": { "institutional": true, "locked": true }` إلى محتوى الكاروسيل، فيختفي المفتاح ويُفرض الوضع. هذا حاجز ضد الأخطاء لا حماية أمنية: كل شيء يعمل في متصفح المستخدم.

ليس في المحرّر سحب أو تغيير حجم للعناصر أصلًا، فالتخطيط تحدّده القوالب. «قفل التخطيط» يعني هنا منع تغيير قالب الشريحة، والإضافات، ورموز التصميم.

## العمل مع Claude وChatGPT

غلاف Next.js ملفّان فقط (`app/layout.js` و`app/page.js`)، وكل ما عداهما React وTailwind عاديّان دون أي واجهة خاصة بـ Next. لذلك يستطيع Claude Code وChatGPT/Codex قراءة المشروع وتعديله مباشرة. وإن احتجت المحرّر في ملف واحد، فملف `carousel.html` الذي تبنيه إضافة Claude يعمل في أي متصفح دون خادم.

## قيود معروفة

- **الاستوديو:**
  - التوليد الفعلي للنص والرسوم يقوم به المساعد المضيف (أو أداة صور متاحة له)، لا أداة الأوامر. لذلك تُسجَّل استدعاءاته عبر `studio asset add --kind generated` و`studio ledger add`، والتوكنز والتكلفة «غير متاح» ما لم يبلغ عنها المزوّد.
  - في بيئات لا تحفظ الملفات بين الجلسات (مثل جلسات المحادثة السحابية) احفظ نسخة بـ `studio backup` واستعدها بـ `studio restore`.
  - بحث المكتبة بالبيانات الوصفية ومعجم مفاهيم صغير؛ الحكم الإبداعي الأخير للمساعد على ملخص أفضل ثلاثة مرشحين.
- **Canva** (حسب مخططات ٢ أكتوبر ٢٠٢٦؛ يعيد السجل فحصها كل جلسة):
  - الموصل لا يختار عائلة الخط، ولا يلوّن كلمة داخل نص، ولا يملك عمليات حركة أو انتقالات أو مدد صفحات أو صوت.
  - أداة رفع الموصل ترفض `.pptx`، وتحوّل `.pdf` إلى معرّف ملف فقط؛ فاستيراد الملف الأصلي يدوي أو عبر Connect API.
  - مسار Connect API مكتوب ومختبر بطلبات مزيّفة، ولم يُجرَّب حيًا لعدم وجود رمز وصول في هذه البيئة.
  - دعم الموصلات الأخرى مبني على مخططاتها كما تُقرأ في الجلسة؛ المخطط التجريبي في الاختبارات ليس لقطة حية لأي مضيف.
  - التحقق من مدة كل مشهد يحتاج دليلًا على حدود المشاهد (ffmpeg أو `sceneCuts`)، وإلا تبقى «لم يُتحقق».
  - استيراد `.pptx` حيًا وتصدير MP4 بمدد مضبوطة لم يُختبرا بعد؛ يحتاج الأول رفع المستخدم، والثاني حفظًا بموافقته.
  - تبقى صورة خلفية القاعدة المنسوخة تحت شكل الخلفية الكامل.
  - لم يُحفظ أي تصميم إلا بموافقة صريحة على المعاينة.
- **OCR:** لا تشغّله الأداة بنفسها؛ تستقبل نتيجته وتعامل فروقها كتحذيرات للمراجعة لا كتصحيحات.

- اختُبر التصدير على Chromium. في Safari وكل متصفحات iOS (محرّك WebKit) قد تُرسم الصورة الأولى قبل فكّ الخطوط والصور المضمّنة. لهذا يجري التصدير جولة إحماء، ويعيد الرسم على WebKit حتى تتطابق نسختان متتاليتان، ويحرّر ذاكرة اللوحات. جرّبنا هذا المسار بمحاكاة معرّف Safari على Chromium، لا على Safari حقيقي.
