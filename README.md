# بصيرة — مولّد الكاروسيل العربي

محرّر كاروسيل عربي بأسلوب Canva لإنستغرام ولينكدإن: ثلاثة مقاسات (عمودي 4:5، ومربع 1:1، وقصة 9:16)، معاينة حيّة، وتصدير PNG لكل شريحة، أو ZIP للكاروسيل كاملًا، أو PDF لكاروسيل لينكدإن. مبني على Next.js (تصدير ثابت) وTailwind CSS 4، ويُنشر على GitHub Pages دون خادم.

## المزايا

- **خمسة قوالب**: غلاف، قائمة خطوات، اقتباس (مع صورة القائل)، قبل/بعد، خاتمة.
- **ثلاثة مقاسات**: 1080×1350 و1080×1080 و1080×1920. مقاس القصص يترك المناطق التي تغطيها واجهة إنستغرام فارغة (٢٥٠ بكسل أعلى و٣٢٠ أسفل).
- **PDF لينكدإن**: ملف واحد، صفحة لكل شريحة بمقاسها الدقيق، يعرضه لينكدإن مستندًا قابلًا للتمرير.
- **ZIP بترتيب النشر**: `01-hook.png` و`02-content.png` … و`05-cta.png`. الرقم يحفظ الترتيب في أي مستعرض ملفات، والدور يصف الصورة.
- **منشور مفرد وبنى جاهزة**: قالب «منشور مفرد» يحمل الخطّاف ← المحتوى ← الدعوة في صورة واحدة، وقائمة «بنية جاهزة» تبدأ منه أو من كاروسيل (خطّاف ← محتوى ← دعوة).
- **فيديو ريلز 9:16**: يحوّل الشرائح إلى فيديو متحرك مدته ١٤ ثانية افتراضيًا. المشهد الأول خطّاف تكتمل حركته في أقل من ثانية، ثم مشاهد المحتوى، ثم الدعوة. يُصدَّر MP4 (H.264) أو WebM داخل المتصفح.
- **الوضع المؤسسي (Agency Kit)**: هوية كحلية وزمردية إلزامية، ومنع كل الألوان الدافئة، وقفل الخط والقوالب والإضافات والهوية. تبقى النصوص والصور فقط قابلة للتعديل.
- **إضافات قابلة للتفعيل**: الترقيم وشريط التقدّم، دعوة السحب والإجراء، العلامة والهوية (شعار وصورة ومعرّف).
- **ألوان آمنة**: ست لوحات جاهزة ولوحة مخصّصة، مع فحص تباين WCAG AA يصحّح الألوان الضعيفة تلقائيًا.
- **أربعة خطوط عربية**: Cairo وTajawal وAlmarai وReadex Pro، تُستضاف ذاتيًا وتُضمَّن في الصور المصدَّرة.
- **أرقام مشرقية أو غربية** للأرقام المولّدة (العدّاد وأرقام الخطوات).
- **حفظ تلقائي** في المتصفح، وتلوين أي كلمة بوضعها بين نجمتين `*هكذا*`.

## التشغيل محليًا

يتطلّب Node.js 20 أو أحدث.

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # الاختبارات الذهبية (node:test، دون مكتبات إضافية)
npm run build    # يُخرج موقعًا ثابتًا في out/
npm start        # يعرض out/ محليًا
```

## النشر على GitHub Pages

1. من إعدادات المستودع: **Settings → Pages → Source → GitHub Actions**.
2. ادفع إلى الفرع `main`. يشغّل [`deploy.yml`](.github/workflows/deploy.yml) الاختبارات، ثم يبني الموقع وينشره.

المسار الأساسي (`/اسم-المستودع`) يُقرأ تلقائيًا من `actions/configure-pages`، فلا حاجة لتعديل أي إعداد عند تغيير اسم المستودع أو استخدام نطاق مخصّص.

## إضافة قالب جديد

كل قالب ملف واحد يصدّر وصفًا للقالب ومكوّن React. مثال: قالب «رقم بارز».

**١. أنشئ `templates/Stat.jsx`:**

```jsx
import FitBox from '../components/FitBox';
import RichText from '../components/RichText';
import { SafeArea } from './shared';

function Stat({ data }) {
  return (
    <SafeArea>
      <FitBox min={40} max={120}>
        <div className="text-center">
          <div className="text-(--c-accent)" style={{ fontSize: '2.4em', fontWeight: 'var(--w-black)', lineHeight: 1.1 }}>
            <RichText text={data.value} />
          </div>
          <p className="mt-[0.4em]" style={{ lineHeight: 1.6 }}>
            <RichText text={data.label} />
          </p>
        </div>
      </FitBox>
    </SafeArea>
  );
}

export default {
  id: 'stat',
  label: 'رقم بارز',
  description: 'إحصائية واحدة بخط كبير',
  fields: [
    { key: 'value', label: 'الرقم', type: 'text' },
    { key: 'label', label: 'الوصف', type: 'textarea', rows: 3 },
  ],
  defaults: { value: '87%', label: 'من القرّاء يحفظون المحتوى المفيد' },
  Component: Stat,
};
```

**٢. سجّله في `templates/index.js`:**

```js
import stat from './Stat';
export const templateList = [cover, listicle, quote, comparison, outro, stat];
```

يظهر القالب فورًا في قائمة «إضافة شريحة»، ويُولَّد محرّر حقوله تلقائيًا من `fields`.

| نوع الحقل | المحرّر | القيمة |
|---|---|---|
| `text` | سطر واحد | نص |
| `textarea` | عدة أسطر | نص (الأسطر تُحترم) |
| `list` | سطر لكل عنصر | مصفوفة نصوص (استعمل `nonEmpty()` عند العرض) |
| `number` | رقم | عدد صحيح ≥ ١ |
| `image` | رفع صورة | `null` أو رابط `data:image/…` |

يستقبل المكوّن `data` (قيم الحقول) و`ctx` الذي يحوي: `index` و`total` و`isLast` و`colors` و`numerals` و`brand`. لإخفاء شارة الحساب على قالبك أضف `hideBrandBadge: true`. لا تفترض ارتفاعًا ثابتًا: `SafeArea` و`FitBox` يتكيّفان مع المقاس النشط ومع مناطق القصص الآمنة (المتغيّرَين `--inset-top` و`--inset-bottom`).

### قواعد كتابة القوالب

1. **ضع المحتوى داخل `SafeArea` ثم `FitBox`**، وحدّد مقاسات العناصر بوحدة `em`. هكذا يكفي بحث واحد عن حجم الخط ليصغّر التكوين كلّه مع الحفاظ على نسبه.
2. **مرّر كل نص يكتبه المستخدم عبر `RichText`**، فهو الذي يعزل المقاطع اللاتينية والأرقام ويلوّن `*الكلمات*`.
3. **الألوان من المتغيّرات فقط**: `bg-(--c-surface)` و`text-(--c-muted)` أو `var(--c-accent)`. الأوزان من `var(--w-regular|bold|black)` لأن كل خط عربي يملك أوزانًا مختلفة.
4. **خصائص منطقية لا فيزيائية**: `ps-*` و`me-*` و`start-*` و`border-s-*` بدل left/right.
5. **الأيقونات الاتجاهية** (الأسهم وعلامات الاقتباس) تأخذ الخاصية `directional`.
6. **الحبوب ذات السطر الواحد** تأخذ `whitespace-nowrap`، و**صفوف `flex-wrap`** تأخذ `w-full`. سبب ذلك أن `html-to-image` ينسخ العروض المحسوبة بتقريب كسري، فقد ينكسر صف ضيّق في الصورة المصدَّرة رغم سلامته في المعاينة.

## إضافة إضافة (Plugin) جديدة

الإضافة طبقة تُرسم فوق كل الشرائح. أنشئ ملفًا في `plugins/` يصدّر:

```js
export default {
  id: 'myPlugin',
  label: 'اسم الإضافة',
  description: 'وصف قصير',
  defaults: { enabled: true /* وأي إعدادات أخرى */ },
  Overlay({ settings, ctx, template }) { /* عناصر بموضع مطلق داخل 1080×1350 */ },
  Settings({ settings, onChange }) { /* onChange({ key: value }) */ },
};
```

ثم أضفها إلى `overlayPlugins` في `plugins/index.js`. تُحفظ إعداداتها وتُدمج تلقائيًا مع المستندات المحفوظة سابقًا.

## كيف تُحلّ المشكلات التقنية الست

**١. اتصال الحروف والخطوط في التصدير.** الصور المصدَّرة تُرسم داخل SVG معزول لا يرى خطوط الصفحة، فإن لم تُضمَّن الخطوط عاد المتصفح إلى خط النظام وانفكّت الحروف أو تغيّر شكلها. الحل في `lib/exportEngine.js`: تُطلب كل الأوزان صراحةً عبر `document.fonts.load()` قبل انتظار `document.fonts.ready`، لأن مجموعات `unicode-range` لا تُحمَّل حتى تُطلب. بعدها تُضمَّن الخطوط داخل الصورة بصيغة base64، وتُخزَّن نتيجة التضمين لكل خط. والخطوط مستضافة ذاتيًا من `@fontsource`، فلا مشاكل CORS. وفي `globals.css`: تصفير `letter-spacing` إلزاميًا (التتبّع يفكّ اتصال الحروف)، و`font-synthesis: none` لمنع التسميك والإمالة المزيّفين، مع `liga` و`calt` و`optimizeLegibility`.

> تنبيه: لا تمرّر `preferredFontFormat` إلى `html-to-image` 1.11. تعبيره النمطي العام يحتفظ بحالته بين قواعد `@font-face`، فيُسقط نحو نصف الخطوط بصمت. اكتُشف هذا أثناء البناء حين ظهر الخط العريض العربي رفيعًا في الصور.

**٢. الحدّة على الشاشات عالية الدقة.** تُرسم كل شريحة دائمًا بـ `pixelRatio: 2` (ضعف المقاس، مثل 2160×2700) مهما كانت دقة جهازك، ثم تُصغَّر بتنعيم عالي الجودة إلى المقاس الأصلي، أو تبقى بالدقة المضاعفة إن اخترتها. التحجيم في المعاينة يقع على غلاف خارجي لا على الشريحة نفسها، فتبقى الصورة المصدَّرة مطابقة بكسلًا بكسل. (`quality` لا تأثير لها على PNG لأنه بلا فقد.)

**٣. Safari وiOS.** قبل كل تصدير تُطلب أوزان الخط للنص الفعلي في الشريحة عبر `document.fonts.load()`، وتُفكّ كل الصور بـ `img.decode()`، ثم ينتظر المحرّك إطارين حتى يستقر التحجيم التلقائي. تسبق الدفعةَ جولةُ إحماء غير مرئية بدقة منخفضة. وعلى WebKit وحده تُعاد كل شريحة حتى تتطابق بصمتا رسمتين متتاليتين (ثلاث إعادات كحدّ أقصى)، وتُحرَّر اللوحات الوسيطة لأن iOS يحدّ ذاكرتها.

**٤. النص المختلط (عربي + إنجليزي + أرقام).** يقسّم `lib/bidi.js` النص إلى مقاطع، ويُعرض كل مقطع يجب أن يبقى من اليسار إلى اليمين (أسماء لاتينية، أرقام، `@معرّف`، `#وسم`، روابط، بريد، هواتف، تواريخ) داخل `<bdi dir="ltr">` بخاصية `unicode-bidi: isolate`. هكذا تبقى `40%` على حالها بدل `%40`، و`+966 50 123 4567` بترتيبه الصحيح. الحالات الذهبية في `tests/bidi.test.js`.
لم يُستعمل `U+200F` (RLM): الفقرات مُعلنة `dir="rtl"` أصلًا، وRLM لا يصلح الترتيب **داخل** المقطع (مجموعات أرقام الهاتف مثلًا)، أما العزل فيصلحه. حيث يستحيل وضع عنصر HTML، كنص `<option>`، تُستعمل محارف العزل LRI/PDI (`U+2066`/`U+2069`).

**٥. التحجيم التلقائي للعناوين.** يقيس `FitBox` الفيض الفعلي ويبحث ثنائيًا عن أكبر حجم خط بين حدّين يملأ المساحة دون تجاوز، ويعيد القياس عند تغيّر النص أو الحجم أو اكتمال تحميل الخط. اختير القياس بدل عدّ الحروف لأن عرض الحروف العربية يتفاوت كثيرًا بين الخطوط وأشكال الحرف. وإن لم يتّسع النص حتى بأصغر حجم مقروء، فلا يُصغَّر أكثر، بل يُنبَّه المستخدم في اللوحة والمصغّرات.

**٦. انعكاس التخطيط والأيقونات.** تُستعمل الخصائص المنطقية (`start` و`end` و`ps` و`me` و`border-s`) و`gap` في كل مكان، والأيقونات الاتجاهية تنعكس عبر `rtl:-scale-x-100`. ولم يُستعمل `rtl:flex-row-reverse` عمدًا: تحت `dir="rtl"` يجري `flex-row` من اليمين أصلًا، فعكسه يعيده إلى ترتيب اليسار. وكذلك `space-x-reverse` غير لازم مع `gap`.

## إضافة Claude: `arabic-carousel`

مجلد [`claude-plugin/`](claude-plugin) إضافة Claude جاهزة. تطلب من Claude «اعمل لي كاروسيل عن…»، فيكتب نصوص الشرائح ويسلّمك **ملف HTML واحدًا** فيه المحرّر كاملًا، معبّأً بالمحتوى وجاهزًا للتعديل والتصدير. الملف يعمل دون إنترنت، لأن الخطوط والمكتبات مضمّنة داخله.

**التثبيت في Claude (الويب أو التطبيق):** حمّل `arabic-carousel-plugin.zip` وارفعه من صفحة الإضافات. لإنتاج الملف بنفسك:

```bash
npm run build:plugin   # → dist/arabic-carousel-plugin.zip
```

**التثبيت في ChatGPT وCodex:** الملف نفسه يعمل هناك أيضًا. فيه `plugin.json` في الجذر بصيغة Agent Plugins المحايدة التي يقرؤها ChatGPT وCodex، و`.claude-plugin/plugin.json` الذي يقرؤه Claude، وكلاهما يشير إلى المهارة نفسها في `skills/`. ارفعه من «Upload plugin» في ChatGPT على الويب. يتطلّب ذلك، حسب OpenAI، صلاحية رفع الإضافات أو أن تكون مالك مساحة العمل أو مديرها.

**التثبيت في Claude Code:** المستودع نفسه سوق إضافات:

```
/plugin marketplace add dropazaabal-design/baseera
/plugin install arabic-carousel@baseera
```

**كيف تعمل:** تكتب المهارة (`skills/arabic-carousel/SKILL.md`) محتوى الكاروسيل بصيغة JSON. بعدها يتحقق السكربت `build_carousel.py` من الحقول والأنواع، وينبّه إلى أخطاء الكتابة العربية (الترقيم اللاتيني، والتطويل، ومحارف الاتجاه)، ثم يحقن المحتوى في `assets/carousel.html`. هذا الملف هو المحرّر نفسه مبنيًا من كود المستودع، فلا توجد نسخة ثانية من القوالب تحتاج مزامنة.

بعد أي تعديل على القوالب أو الإضافات أو الخطوط أو الأنماط، شغّل `npm run build:plugin` وأودع النتيجة. فحص CI في كل PR يرفض أي ملفات إضافة قديمة.

## محرّك فيديو الريلز

**ارسم مرة، ركّب مرات.** لا يعيد المحرّك رسم النص العربي على اللوحة في كل إطار بـ `fillText`، فذلك يتجاوز العزل الاتجاهي والتحجيم التلقائي وأوزان الخطوط. بدلًا من ذلك، تُرسم كل شريحة بمقاس القصة خارج الشاشة بالمحرّك نفسه الذي يصدّر PNG. منها تُلتقط صورة خلفية تخفي العناصر المتحركة، ثم صورة شفافة لكل عنصر يحمل `data-anim` (`rise` أو `fade` أو `pop`). كل إطار بعد ذلك تركيب لهذه الصور فقط (شفافية وإزاحة وتكبير)، فيبقى اتصال الحروف وترتيب النص المختلط مطابقًا للمعاينة في كل إطار. والعناصر تتحرك كاملة، لا حرفًا حرفًا، لأن الحرف العربي يتصل بجاره.

**التوقيت** (`lib/timeline.js`): ١٤ ثانية افتراضيًا. الخطّاف ثانيتان تكتمل حركته في أقل من ثانية، مع تقريب سريع عند كل قطع. الدعوة ٢٫٥ ثانية، ومشاهد المحتوى تتقاسم الباقي بنسبة زمن قراءتها. تدخل العناصر متتابعة خلال أول ٤٠٪ من مشهدها، وينبّه المحرّر حين يكون نص المشهد أطول من زمن ظهوره.

**الترميز** (`lib/video.js`): المسار الأساسي هو WebCodecs عبر `mediabunny` بطوابع زمنية صريحة، فيخرج الفيديو بطول الثواني المطلوبة بالضبط مهما كان الجهاز بطيئًا، وأسرع من الزمن الحقيقي. يُجرَّب MP4/H.264 أولًا، ثم WebM/VP9 حيث لا يتوفر مرمّز H.264. المتصفحات بلا WebCodecs تستعمل `MediaRecorder` في الزمن الحقيقي. أثناء التجهيز والترميز تظهر نسبة التقدم إطارًا بإطار مع زر إلغاء، ويطلب المتصفح تأكيدًا قبل إغلاق الصفحة.

لإضافة حركة إلى قالب جديد، ضع `data-anim` على العناصر التي تريدها. لا تضعها متداخلة، ولا على عنصر يحمل `transform`.

## الوضع المؤسسي (Agency Kit)

السياسة كلها في `plugins/agencyKit.js`: اللوحات المسموحة، والخط، والإضافات الإلزامية. تُطبَّق فوق اختيارات المستخدم وقت العرض ولا تحلّ محلّها، فإيقاف الوضع يعيد تصميمه كما كان. تُعطَّل اللوحات غير المسموحة مع ذكر السبب («ألوان دافئة» أو «خارج الهوية»)، ويُقفل الباقي عبر `<fieldset disabled>` الذي يعطّل كل عنصر داخله.

مفتاح التبديل وحده لا يكفي حوكمةً، لأن أي مستخدم يستطيع إيقافه. لذلك تقفل الجهة ملفها بإضافة `"governance": { "institutional": true, "locked": true }` إلى محتوى الكاروسيل، فيختفي المفتاح ويُفرض الوضع. هذا حاجز ضد الأخطاء لا حماية أمنية: كل شيء يعمل في متصفح المستخدم.

ليس في المحرّر سحب أو تغيير حجم للعناصر أصلًا، فالتخطيط تحدّده القوالب. «قفل التخطيط» يعني هنا منع تغيير قالب الشريحة، والإضافات، ورموز التصميم.

## العمل مع Claude وChatGPT

غلاف Next.js ملفّان فقط (`app/layout.js` و`app/page.js`)، وكل ما عداهما React وTailwind عاديّان دون أي واجهة خاصة بـ Next. لذلك يستطيع Claude Code وChatGPT/Codex قراءة المشروع وتعديله مباشرة. وإن احتجت المحرّر في ملف واحد، فملف `carousel.html` الذي تبنيه إضافة Claude يعمل في أي متصفح دون خادم.

## قيود معروفة

- اختُبر التصدير على Chromium. في Safari وكل متصفحات iOS (محرّك WebKit) قد تُرسم الصورة الأولى قبل فكّ الخطوط والصور المضمّنة. لهذا يجري التصدير جولة إحماء، ويعيد الرسم على WebKit حتى تتطابق نسختان متتاليتان، ويحرّر ذاكرة اللوحات. جرّبنا هذا المسار بمحاكاة معرّف Safari على Chromium، لا على Safari حقيقي.
- الإيموجي يُرسم بخط الإيموجي في جهاز من يصدّر.
- الفيديو بلا صوت؛ أضف الموسيقى من تطبيق المنصة. ولم يُختبر ترميز MP4/H.264 هنا، لأن Chromium مفتوح المصدر لا يحتوي مرمّز H.264؛ اختُبر مسار WebM/VP9 ومسار MediaRecorder.
- الحفظ التلقائي يعتمد على `localStorage` (نحو ٥ ميغابايت)، لذا يُصغَّر الشعار والصورة الشخصية عند الرفع إلى ٤٨٠ بكسل بصيغة WebP.
