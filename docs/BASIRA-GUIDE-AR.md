# بصيرة — الدليل الكامل ومكتبة البرومبتات

**الإصدار:** دليل 1.0 لإضافة «بصيرة» (arabic-carousel) 1.7.0 · **التاريخ:** 4 أكتوبر 2026

هذا دليل عملي لمن يريد استعمال «بصيرة» دون قراءة الكود: افتح الدليل، ابحث عن المهمة، انسخ البرومبت، وغيّر ما بين الأقواس فقط.
كل ما يصفه الدليل موجود فعلًا في المستودع ومختبَر. وما لم يُبنَ بعد مكتوب بجانبه صراحةً: **قيد التطوير**.

## كيف تستعمل هذا الدليل

- **ابحث بالكلمة:** كاروسيل، ريل، هوك، خوارزمية، X، Facebook، Instagram، تصميم، كابشن، تعديل، Canva.
- **ابحث بالرمز:** لكل برومبت رمز ثابت مثل `P-CAR-004` أو `P-ALG-002`. فهرس كل الرموز في آخر الدليل.
- **انسخ من المربع الرمادي فقط:** كل برومبت داخل مربع مستقل جاهز للنسخ.
- **المتغيرات بين قوسين مربعين:** `[TOPIC]` و`[AUDIENCE]` وأمثالها. استبدلها بكلامك واحذف القوسين (التفاصيل في القسم 4.4).
- **لا يلزمك ملء كل شيء:** بصيرة تستنتج ما لم تذكره (الجمهور، النبرة، عدد الشرائح…) وتقول لك ماذا اختارت.

## 1. ما هي بصيرة

### 1.1 بصيرة في سطور

بصيرة استوديو تصميم ومحتوى عربي لوسائل التواصل، يعمل داخل المساعد (Claude أو ChatGPT أو Codex) كإضافة اسمها `arabic-carousel`.
تكتب طلبك بالعربية، فتخطط بصيرة الفكرة وتكتب النص وتصمم الصفحات فعلًا (لا وصفًا)، ثم تفحصها، وتحلل ملاءمتها لكل منصة قبل النشر، وتسلّمك ملفًا تعدّله وتصدّر منه.

### 1.2 ماذا تصنع

- **كاروسيل Instagram** بمقاس 4:5 (1080×1350)، وكل شريحة عناصر مستقلة قابلة للتعديل.
- **منشور مفرد** (صورة واحدة) بمقاس 4:5 أو مربع 1:1.
- **ستوري وريل** بمقاس 9:16 (1080×1920): مخطط مشاهد بمدد وحركة، وفيديو يُصدَّر من المحرر، أو تصميم مشاهد في Canva.
- **نصوص المنصات:** منشورات X وسلاسلها، ومنشورات Facebook، والكابشن والهوكات (يكتبها المساعد، وتقيسها بصيرة).
- **ملف المحرر** (HTML يعمل دون إنترنت): تعدّل فيه بالكلام وتصدّر PNG لكل صفحة، أو ZIP بترتيب النشر، أو PDF للينكدإن، أو فيديو ريلز.
- **ملف PowerPoint** قابل للتعديل، أو **تصميم في Canva** عناصره منفصلة.
- **ملف الموضوع الكامل:** Storyboard، والنسخة الجاهزة، وبرومبت توليد لكل شريحة مع البرومبت السلبي، وموجز للمصمم.
- **تقرير ذكاء المنصات:** درجة ملاءمة لكل من X وInstagram وFacebook مع أسبابها وثقتها وتعديلات مقترحة.

### 1.3 لمن

- صانع المحتوى العربي الذي ينشر كاروسيلات ومنشورات وريلز بانتظام.
- الفرق والوكالات التي تحتاج هوية ثابتة ونصًا عربيًا سليمًا في كل تصدير.
- من لا يجيد التصميم ويريد نتيجة مقروءة على الهاتف دون أخطاء عربية.
- من يريد أن يعرف قبل النشر أين تضعف فكرته، بلغة الأرقام لا الانطباع.

### 1.4 المشكلات التي تحلها

| المشكلة | ما تفعله بصيرة |
|---|---|
| حروف عربية مقطعة أو معكوسة في التصدير | مكوّن واحد للنص العربي يقيس ويرسم في Chromium ويفحص الاتصال والاتجاه |
| نص كثير لا يُقرأ على الهاتف | حدود دنيا للخط، وإعادة توزيع، واقتراح اختصار بعدد الكلمات بالضبط |
| تصاميم متشابهة أو بلا هوية | تسعة أساليب جاهزة، وهوية محفوظة (ألوان وخطوط وقيود)، ومكتبة تصاميم تُعاد صياغتها |
| تعديل صغير يهدم تصميمًا جيدًا | تعديل موضعي بالكلام: «كبّر العنوان الثاني» يمسّ عنصرًا واحدًا |
| لا تعرف هل ستنجح الفكرة | تحليل لكل منصة بأسباب ومصادر وثقة، ويتعلم من أداء حسابك المستورد |
| تكلفة ذكاء اصطناعي غير ضرورية | القياس محلي بلا رموز (tokens)، والكاش يمنع تكرار التوليد، وسجل لكل استدعاء |

### 1.5 كيف تعمل المحركات معًا

```text
فكرة أو نص أو صورة مرجعية
↓
فهم الطلب (المنصة، الصيغة، عدد الصفحات، الهوية)
↓
التخطيط: إعادة استعمال من مكتبتك أو اتجاه جديد
↓
كتابة المحتوى (المساعد) وتدقيق العربية
↓
التصميم (الاستوديو: تكوينات وأسلوب وهوية)
↓
فحص الجودة (الفيض، الأحجام، التباين، الهوية)
↓
تحليل الخوارزمية (Algorithm Intelligence)
↓
التحسين بتعديلات موضعية
↓
التصدير: PNG / ZIP / PDF / فيديو / PowerPoint / Canva
↓
بعد النشر: استيراد النتائج ← يتعلم الحساب ← توصيات أدق
```

### 1.6 مكونات بصيرة الموجودة فعلًا

| المكوّن | ماذا يفعل | أين |
|---|---|---|
| مهارة `arabic-carousel` | المدير الفني: البوست والكاروسيل والستوري، والتعديل بالمحادثة | داخل الإضافة |
| مهارة `carousel-director` | يبني كاروسيلًا كاملًا من فكرة موضوع فقط، مع الملف الكامل والبرومبتات | داخل الإضافة |
| مهارة `arabic-reels` | يحوّل فكرة أو كاروسيلًا إلى ريل 9:16 بمشاهد ومدد وحركة | داخل الإضافة |
| مهارة `canva-arabic` | يبني ويعدّل في حساب Canva الحقيقي ويقرأ النتيجة ويقارنها حرفًا حرفًا | داخل الإضافة |
| مهارة `arabic-proofing` | تدقيق النص العربي وتنضيده ومقارنة المنقول بالمعتمد | داخل الإضافة |
| مهارة `creator-memory` | «ذوقي وهويتي»: الحسابات والهويات والتفضيلات بنطاقها | داخل الإضافة |
| الاستوديو `studio` | أداة أوامر: التخطيط والتصميم والفحص والتعديل والمكتبة والذاكرة والتحليل | `studio.mjs` في الإضافة |
| المحرر | ملف HTML: تبويبات المحتوى والعناصر والجودة وذكاء المنصات والذوق والسجل، ومعاينة الهاتف، والتصدير | الملف الذي تسلّمه بصيرة |
| ArabicText | المسؤول الوحيد عن النص العربي في التصميم والفيديو | داخل المحرر والتصدير |
| Algorithm Intelligence | درجات X وInstagram وFacebook، والأسباب، والثقة، والتوصيات، والتعلم من سجل الحساب | `studio analyze-…` وتبويب «ذكاء المنصات» |
| الأساليب التسعة والتكوينات الخمسة عشر | لغات بصرية جاهزة وأنواع شرائح | `studio styles` و`studio compositions` |

### 1.7 ما ليس في بصيرة اليوم

حتى لا تطلب ما لا يوجد:

- **النشر والجدولة:** بصيرة لا تنشر على المنصات ولا تجدول. أنت تنشر، ثم تستورد النتائج.
- **جلب الأداء دون مفاتيح:** القراءة المباشرة من واجهات Instagram وFacebook وX تحتاج مفاتيحك في بيئة الأوامر. دونها تستورد ملف JSON أو CSV.
- **محرك بحث داخلي:** البحث يقوم به المساعد بأدواته إن كانت متاحة في بيئتك. بصيرة لا تبحث في الإنترنت بنفسها.
- **مولّد صور فوتوغرافية:** الرسوم التي ترسمها بصيرة رسوم مسطحة (SVG) يرسمها المساعد. أما الصور الواقعية فتكتب لها برومبتات لأداة صور خارجية.
- **متتبع تجارب A/B على المنصة:** المقارنة بين النسخ قبل النشر متاحة. أما تتبع تجربة حية فـ**قيد التطوير**: انشر النسختين واستورد نتائجهما.
- **تصدير فيديو أطول من 30 ثانية من المحرر:** مدد التصدير المتاحة 10 و14 و20 و30 ثانية. الريل الأطول يُخطط أو يُبنى في Canva.
- **أساليب بأسماء غير موجودة** (مثل Doodle): انظر جدول الأساليب في القسم 17 لما هو موجود وما هو **قيد التطوير**.

## 2. التثبيت وأين تعمل

| أين تعمل | ماذا تفعل |
|---|---|
| Claude Code | `/plugin marketplace add dropazaabal-design/baseera` ثم `/plugin install arabic-carousel@baseera` (وداخل مستودع بصيرة نفسه تُعرض تلقائيًا) |
| تطبيق Claude أو موقعه | ارفع `arabic-carousel-plugin.zip` من صفحة الإضافات |
| ChatGPT أو Codex | ارفع `arabic-carousel-chatgpt.zip` من «Upload plugin»، واذكر `$arabic-carousel` في رسالتك |

**شرط مهم:** التصميم بالأساليب والذاكرة والتحليل يحتاج بيئة فيها Node 18 أو أحدث (Claude Code أو Codex أو محادثة فيها تنفيذ أوامر).
دونها تعمل المهارة بالمسار الكلاسيكي (قوالب أبسط) وتقول ذلك صراحة.

**ما تتسلمه عادة:** ملف المحرر `design.html`. افتحه في Chrome أو Edge أو Firefox أو Safari، وعدّل من تبويب «المحتوى» أو بشريط «عدّل بالمحادثة»، وصدّر من زر «تصدير».

## 4. كيف تكتب برومبت لبصيرة

### 4.1 الإطار

استعمل من هذه الحقول ما تعرفه فقط، واترك الباقي:

```text
المهمة:
المنصة:
نوع المحتوى:
الموضوع:
الجمهور:
الهدف:
النبرة:
عدد الشرائح/المشاهد:
الهوية البصرية:
القيود:
المخرجات:
```

| الحقل | أمثلة | إن تركته |
|---|---|---|
| المهمة | صمم، حلل، حسّن، حوّل، اكتب | تستنتجها من الفعل الأول في كلامك |
| المنصة | Instagram، X، Facebook | Instagram للكاروسيل والريل |
| نوع المحتوى | كاروسيل، منشور مفرد، ريل، سلسلة، كابشن | من كلماتك («كاروسيل»، «بوست مفرد»، «ريل») |
| الموضوع | جملة الفكرة | **لا يُستنتج: اكتبه دائمًا** |
| الجمهور | طلاب، رواد أعمال، أمهات جدد | يختار المساعد جمهورًا منطقيًا ويذكره |
| الهدف | حفظ، مشاركة، نقاش، متابعة، بيع | تعليمي ← حفظ ومشاركة، توعوي ← مشاركة وتعليق |
| النبرة | هادئة، حازمة، ودودة، تحذيرية | من هويتك المحفوظة أو من الموضوع |
| عدد الشرائح | 6، 7، 10 | من طبيعة المحتوى (عدد البنود + غلاف + خاتمة) |
| الهوية البصرية | ألوان، خطوط، أسلوب | هويتك المحفوظة، وإلا اختيار مناسب للموضوع |
| القيود | بلا وجوه، أرقام غربية، بلا إنجليزية | قيود هويتك المحفوظة |
| المخرجات | ملف المحرر، ZIP، PDF، ملف للمصمم، تحليل | ملف المحرر |

### 4.2 ما تستنتجه بصيرة وحدها

- **عدد الصفحات:** «كاروسيل» بلا عدد ← تقرره من المحتوى. «٧ شرائح» ← سبع بالضبط، وفحص الجودة يرفض غير ذلك.
- **المقاس:** 4:5 افتراضيًا، و9:16 للستوري والريل، و1:1 إن قلت «مربع».
- **إعادة الاستعمال:** تبحث في مكتبتك عن تصميم مناسب قبل أن تصمم من الصفر، إلا إن قلت «شيء جديد».
- **ذوقك:** تطبق تفضيلاتك المحفوظة الصريحة فقط، وطلبك الحالي يتقدم عليها دائمًا.

### P-WRITE-004 — برومبت خبير

```text
المهمة: كاروسيل إنستغرام 4:5 من 8 شرائح
الموضوع: [TOPIC]
الجمهور: [AUDIENCE]
الهدف الأول: [GOAL] — والهدف الثاني: متابعة الحساب

البنية:
1. غلاف: رقم + نتيجة مؤلمة، 8 كلمات أو أقل، بلا سؤال عام
2. تمهيد: لماذا يهمك هذا الآن (سطران)
3–7. بند في كل شريحة: عنوان قصير + سطرا شرح + مثال واحد ملموس
8. خاتمة: سؤال يحدد الإجابة («أي رقم…؟») + دعوة حفظ

القيود:
- 30 كلمة كحد أقصى للشريحة، و12 للغلاف
- كلمة مظللة واحدة في كل عنوان
- لا تكرر التكوين نفسه في شريحتين متتاليتين
- أرقام غربية، ولا إنجليزية في التصميم إلا اسم الحساب

التقييم:
- افحص الجودة وأصلح الأخطاء قبل التسليم
- حلّل لـInstagram، ونفّذ التوصيات المقيسة ذات الأولوية العالية فقط
- أعد التحليل واذكر الدرجة قبل وبعد

المخرجات: ملف المحرر، والدرجة قبل وبعد، وقائمة التعديلات المنفذة
```

### 4.4 المتغيرات

استبدل المتغير وما بين القوسين بكلامك. أمثلة:

| المتغير | معناه | مثال |
|---|---|---|
| `[TOPIC]` | الموضوع أو العنوان | 6 أخطاء تجعلك أقل احترامًا دون أن تشعر |
| `[PLATFORM]` | المنصة | Instagram / X / Facebook |
| `[AUDIENCE]` | الجمهور | طلاب الجامعة |
| `[GOAL]` | الهدف | الحفظ / المشاركة / النقاش / المتابعة |
| `[TONE]` | النبرة | هادئة وواثقة |
| `[STYLE]` | الأسلوب البصري | تحريري هادئ / مجلة جريئة / تعليمي بتظليل |
| `[NUMBER_OF_SLIDES]` | عدد الشرائح | 7 |
| `[FORMAT]` | المقاس | 4:5 / 1:1 / 9:16 |
| `[TEXT]` | نص تلصقه | منشورك كما هو |
| `[HANDLE]` | اسم حسابك | @kitabwbs |
| `[CHANGE]` | التعديل المطلوب | كبّر عنوان الغلاف قليلًا |
| `[SECONDS]` | مدة الريل | 30 |

**القاعدة:** إن لم تعرف قيمة متغير فاحذف سطره كله، ولا تتركه بين قوسين.

### 4.5 القالب والمثال

البرومبتات المهمة في هذا الدليل لها **قالب** (بمتغيرات) و**مثال** (مملوء). القالب للنسخ، والمثال ليريك الشكل بعد الملء.

## 8. الريلز

**ما تفعله بصيرة فعلًا:** تحوّل الفكرة أو الكاروسيل إلى مشاهد 9:16 (1080×1920). المشهد الأول هوك من 7 كلمات أو أقل يظهر من أول جزء من الثانية، ومدة كل مشهد محسوبة من كمية نصه (2 إلى 6 ثوانٍ)، وتسع مشاهد على الأكثر. الحركة للعنصر كاملًا (ظهور، صعود، تكبير)، ولا تُحرَّك الحروف العربية حرفًا حرفًا حتى لا ينكسر اتصالها.

**المخرجات المتاحة:**

- فيديو من المحرر (زر «تصدير» ← «فيديو ريلز») بمدة 10 أو 14 أو 20 أو 30 ثانية، صامت.
- أو مشاهد قابلة للتعديل في Canva بمددها وحركتها (مهارة `canva-arabic`).
- الريل الأطول من 30 ثانية يُخطط ويُبنى في Canva. **تصديره من المحرر قيد التطوير.**
- **لا موسيقى ولا صوت تلقائيًا:** أضف الصوت بنفسك إن أردت.
- **بلا وجوه:** الريل نصي بالكامل، والرسوم مسطحة.

## 11. ذكاء المنصات: Algorithm Intelligence

### 11.1 ما هو

**Basira Algorithm Intelligence Engine** يحلل المحتوى قبل نشره لكل من X وInstagram وFacebook، ويعطيك:

- **Platform Fit Score** (من 0 إلى 100) لكل منصة، ومتوسطها «إمكانات المحتوى إجمالًا».
- درجات منفصلة: الافتتاحية (Hook)، والاستبقاء (Retention)، والنقاش (Conversation)، والمشاركة (Share)، والحفظ (Save) حيث ينطبق، والنقر، وجودة المحتوى، وملاءمة الصيغة، وخطر التفاعل السلبي (Negative Risk)، والتوافق مع تاريخ حسابك.
- **أسباب كل درجة:** ما رفعها وما خفضها، بالأرقام، ومن أي خاصية في المحتوى.
- **درجة الثقة** وأسبابها.
- **تعديلات مقترحة:** كل تعديل مرتبط بشيء مقيس (عدد الكلمات، طول الجملة الأولى، الوعد في الغلاف…)، مع أثره المتوقع وفق النموذج.
- **تشخيص كل شريحة** في الكاروسيل: عدد كلماتها، وكثافتها، وكم كلمة تحذف بالضبط.

### 11.2 ما تعنيه الدرجة وما لا تعنيه

| الدرجة **تعني** | الدرجة **لا تعني** |
|---|---|
| مدى توافق المحتوى مع ما تعرفه بصيرة عن المنصة وعن حسابك، وفق نموذجها الحالي | احتمال الانتشار. 91 ليست «91٪ فرصة أن ينتشر» |
| مقارنة بين نسختين من المحتوى نفسه، أو بين محتوياتك | معرفة بخوارزميات المنصات الخاصة. بصيرة لا تدّعي ذلك |
| أين يضعف المحتوى ولماذا | ضمان نتيجة. الأداء يتأثر بالتوقيت والجمهور وأشياء لا تُرى |

**تنبيه من بصيرة نفسها:** لا تدّعي بصيرة الوصول إلى خوارزميات الترتيب الخاصة بالمنصات. الدرجات تقديرات مبنية على معلومات المنصات المنشورة وخصائص المحتوى وأداء حسابك السابق.

### 11.3 من أين تأتي المعلومة (مصدر الإشارة)

كل إشارة في التحليل تحمل مصدرها:

| المصدر | معناه | مثال |
|---|---|---|
| رسمي (official) | ما تعلنه المنصة في وثائقها | Instagram يتنبأ بإكمال الكاروسيل وبالإرسال في الرسائل |
| كود منشور (public-source-code) | ما في الكود الذي نشرته المنصة | نظام X يجمع تنبؤات الرد وإعادة النشر والإبلاغ بأوزان |
| بحث (research) | دراسة منشورة | مقياس سهولة القراءة العربية |
| تاريخ الحساب (historical) | نتائج منشوراتك المستوردة | «افتتاحيات القوائم حققت +29٪ مشاركات على حسابك» |
| قياس (derived) | قياس مباشر من المحتوى | عدد الكلمات، طول الجملة الأولى |
| تقدير قاعدي (heuristic) | قاعدة عملية من بصيرة | «السؤال المحدد يدفع للتعليق أكثر من العام» |

### 11.4 التحليل العام والتحليل بتاريخ الحساب

- **دون بيانات حسابك:** تحليل عام بثقة **منخفضة** دائمًا، ويقول التقرير ذلك صراحة: «نموذج المنصة العام فقط».
- **بعد استيراد نتائج منشوراتك:** خط أساس لحسابك (الوسيط لا المتوسط)، وأنماط مثبتة بعينات كافية، وأوزان تتكيف مع حسابك، فترتفع الثقة.
- **العينة الصغيرة لا تقول شيئًا:** النمط يحتاج 8 منشورات على الأقل في كل جهة، واختبارًا إحصائيًا يسنده.
- **المنشور الفيروسي الواحد لا يصير قاعدة:** خط الأساس بالوسيط، والمنشور الشاذ يُعلَّم ولا يحرّك الوسيط.

### 11.5 كيف تشغّله

- **في المحادثة:** اطلب التحليل بالكلام (البرومبتات أدناه).
- **في المحرر:** تبويب «ذكاء المنصات». يحلل تلقائيًا بعد كل تعديل، ويستورد ملف نتائج منشوراتك (JSON أو CSV) ويحفظه في المتصفح.
- **بالأوامر:** `basira analyze-carousel design.json --platform instagram` (التفاصيل في القسم 34).
- **التحليل محلي وبلا تكلفة:** القياس والدرجات والتوصيات تعمل دون أي استدعاء للذكاء الاصطناعي. الحكم الدلالي (الفضول، الجِدّة، الفائدة) اختياري ويُحفظ ليُستعمل مرة واحدة.

## 17. التصميم والأساليب

### 17.1 الأساليب الموجودة فعلًا

في بصيرة اليوم **تسعة أساليب جاهزة** (حالتها «قابل لإعادة الاستعمال» بعد مراجعة كل تكوين). الهوية تعطي لون التمييز والخطوط، والأسلوب يعطي التوزيع والزخرفة والخلفيات.

| الأسلوب | الاسم في بصيرة | يناسب | قوته | لا تستعمله حين |
|---|---|---|---|---|
| تعليمي بتظليل | `mint-highlight` | مفاهيم، قوانين، أخطاء، خطوات | وضوح شديد، فكرة لكل شريحة، تظليل الكلمة المهمة | تريد صورًا كثيفة أو جوًا عاطفيًا |
| تحريري هادئ | `quiet-editorial` | مقالات وقوائم هادئة | فراغ واسع ولون تمييز واحد | المقارنات (يرفضها) والكولاج |
| مجلة جريئة | `magazine-bold` | نصائح سريعة بإيقاع قوي | غلاف وخاتمة داكنان، عناوين ثقيلة | المحتوى التأملي الهادئ |
| سويسري | `swiss-editorial` | شرح منظم، خطوات، أطر عمل | عمود واحد صارم وعمود تمييز رأسي | الاقتباسات (يرفضها) |
| صحفي | `newspaper-editorial` | رأي، تحليل، أرقام | ترويسة بخطين وبنود مفصولة بخطوط | المحتوى المرح الخفيف |
| أحادي ليلي | `monochrome-editorial` | تأمل واقتباسات | صفحات داكنة بلون واحد داخل إطار | المقارنات (يرفضها) |
| كولاج تحريري | `collage-cutout` | كتب، ذكريات، قصص | قصاصات ورقية مائلة وشريط لاصق، تناوب داكن وفاتح | المحتوى المؤسسي الرسمي |
| بسيط هادئ | `quiet-minimal` | جملة واحدة، تأمل | مسافات واسعة جدًا | المقارنة والإطار (يرفضهما) |
| هندسي | `geometric-editorial` | تعليم حيوي | دوائر صلبة وبطاقات مملوءة وشارات أرقام | الاقتباسات (يرفضها) |

**تنبيه صادق:** التكوينات التعليمية الأربعة (غلاف برقم، فكرة بستة توزيعات، مسار، خاتمة بأزرار) متاحة مع `mint-highlight` وحده الآن. الأساليب الأخرى لم تُراجع معها بعد، وبصيرة تقول ذلك ولا تدّعيه.

### 17.3 برومبتات التصميم

#### P-DESIGN-001 — اختر الأسلوب المناسب

```text
اعرض الأساليب الجاهزة في بصيرة، ورشّح أنسب اثنين لموضوع [TOPIC] مع السبب،
وما الذي يرفضه كل منهما من أنواع الشرائح.
```

#### P-DESIGN-002 — تحريري هادئ (Editorial)

```text
صمم الكاروسيل عن [TOPIC] بأسلوب «تحريري هادئ»:
عنوان كبير في أعلى الصفحة، وفراغ واسع، ولون تمييز واحد من هويتي في كل صفحة.
لا تستعمل شرائح مقارنة في هذا الأسلوب.
```

#### P-DESIGN-003 — كولاج تحريري (Editorial / Paper Collage)

```text
صمم كاروسيلًا عن [TOPIC] بأسلوب «كولاج تحريري»:
قصاصات ورقية مائلة قليلًا خلف المحتوى وشريط لاصق، وصفحات تتناوب بين الداكن والفاتح.
الرسوم مسطحة بلا وجوه ولا نص داخلها.
```

#### P-DESIGN-004 — بسيط هادئ (Minimal)

```text
صمم بوستًا بجملة واحدة عن [TOPIC] بأسلوب «بسيط هادئ»:
النص في الوسط، ومسافات واسعة جدًا، ونقطة تمييز صغيرة فقط.
```

#### P-DESIGN-005 — سويسري (Swiss)

```text
صمم كاروسيل خطوات عن [TOPIC] بأسلوب «سويسري»:
عمود واحد يبدأ من أعلى الصفحة، بلا بطاقات ولا زوايا، وعمود تمييز رأسي.
```

#### P-DESIGN-006 — مجلة جريئة (Magazine / Bold Typography)

```text
صمم كاروسيل نصائح سريعة عن [TOPIC] بأسلوب «مجلة جريئة»:
غلاف وخاتمة داكنان، وعناوين ثقيلة كبيرة، ورقم شبحي في صفحات المحتوى،
وشريحة «جملة طباعية» واحدة بأقوى فكرة.
```

#### P-DESIGN-007 — صحفي (Newspaper)

```text
صمم كاروسيل رأي وتحليل عن [TOPIC] بأسلوب «صحفي»:
ترويسة بخطين أسودين، وعناوين ثقيلة، وبنود مفصولة بخطوط،
والتمييز في التمهيد وكلمة العنوان فقط.
```

#### P-DESIGN-008 — أحادي ليلي (Dark Editorial)

```text
صمم كاروسيلًا تأمليًا عن [TOPIC] بأسلوب «أحادي ليلي»:
صفحات بلون واحد هو الأزرق الليلي المشتق من هويتي بتدرجاته، داخل إطار رفيع.
```

#### P-DESIGN-009 — أبيض تحريري (White Editorial)

```text
صمم الكاروسيل بخلفية بيضاء كاملة وعناوين سوداء عريضة،
ولون الهوية للتمييز فقط في كلمة واحدة بكل عنوان.
اختر بين «تحريري هادئ» و«تعليمي بتظليل» حسب نوع المحتوى، وقل لي لماذا.
```

#### P-DESIGN-010 — هندسي (Geometric)

```text
صمم كاروسيلًا تعليميًا حيويًا عن [TOPIC] بأسلوب «هندسي»:
دوائر صلبة بلون التمييز تخرج من حافة الصفحة، وبطاقات مربعة مملوءة، وشارات أرقام دائرية.
```

#### P-DESIGN-011 — تعليمي بتظليل

```text
صمم الكاروسيل عن [TOPIC] بأسلوب «تعليمي بتظليل»:
خلفية بيضاء، وعناوين سوداء عريضة، وتظليل خلف الكلمة المهمة في كل عنوان،
وإطارات رفيعة وأسهم خفيفة، وفكرة واحدة لكل شريحة.
نوّع التكوين: نص كبير، مربع مركزي، خلاصة مظللة، رقم كبير، مسار بسهم، دعوة بأزرار.
```

#### P-DESIGN-012 — التظليل بلون هويتي

```text
استعمل أسلوب «تعليمي بتظليل» لكن بلون هويتي الأساسي بدل الأخضر.
```

#### P-DESIGN-013 — محتوى قائم على البيانات (Data-driven)

```text
صمم كاروسيلًا قائمًا على الأرقام عن [TOPIC] بأسلوب «صحفي»:
كل شريحة رقم واحد كبير، وجملة تشرح معناه، والمصدر في سطر صغير.
لا تضع رقمًا بلا مصدر؛ ما لا مصدر له احذفه وقل لي.
```

#### P-DESIGN-014 — مؤسسي (Corporate Editorial)

```text
صمم هذا المحتوى بطابع مؤسسي رسمي: في المحرر الكلاسيكي فعّل «وضع المؤسسات»
(لوحة agency-navy أو agency-light، وخط Tajawal، وترقيم وعلامة مائية).
بلا ألوان دافئة وبلا زخرفة مرحة.
```

#### P-DESIGN-015 — تناوب داكن وفاتح

```text
صمم الكاروسيل بأسلوب يتناوب بين صفحات داكنة وفاتحة، يبدأ الغلاف داكنًا،
بشرط أن يبقى تباين النص مقروءًا في كل صفحة.
```

#### P-DESIGN-016 — غلاف قوي فقط

```text
احتفظ بكل الشرائح كما هي. أعد تصميم الغلاف فقط ليكون أقوى بصريًا:
رقم كبير أو كلمة واحدة بطلة، وعنوان من 5 كلمات أو أقل.
```

#### P-DESIGN-017 — التصميم مزدحم

```text
التصميم مزدحم. لكل شريحة: احذف عنصرًا زخرفيًا واحدًا إن وجد،
وقسّم النص الطويل على شريحتين بدل تصغير الخط، ثم أعد الفحص.
```

#### P-DESIGN-018 — رسوم بهويتي

```text
ارسم لكل شريحة رسمًا مسطحًا بسيطًا يدل على فكرتها، بألوان هويتي فقط،
بلا وجوه ولا أيدٍ ولا نص داخل الرسم، ثم احفظ الرسوم في مكتبتي لأعيد استعمالها.
```

#### P-DESIGN-019 — إعادة صياغة تصميم ناجح

```text
خذ تصميمي [DESIGN_ID] من المكتبة، وأعد صياغته لموضوع جديد [TOPIC]:
احتفظ بالأسلوب والتكوينات، وغيّر التوزيع قليلًا حتى لا يبدو نسخة.
```

#### P-DESIGN-020 — بلا نسخ لتصميم سابق

```text
صمم كاروسيلًا جديدًا عن [TOPIC] باتجاه بصري جديد تمامًا: شيء جديد،
لا تعِد استعمال أي تصميم من مكتبتي.
```

## 18. الطباعة العربية

بصيرة تمرّر كل نص عربي بمكوّن واحد: يحفظ النص بترتيبه المنطقي، ويعزل الحسابات والأرقام والإنجليزية دون محارف خفية، ويقيس ويرسم في Chromium، ويرفض الخط المفقود بدل استبداله بصمت.
الخطوط المتاحة: Cairo وTajawal وAlmarai وReadex Pro (كلها برخصة مفتوحة).

#### P-TYPO-001 — صحّح اتجاه النص

```text
افحص اتجاه النص في كل شريحة: الحساب @ والأرقام والكلمات الإنجليزية في مواضعها الصحيحة،
وعلامات التنصيص « » في اتجاهها، ولا شيء معكوس.
أصلح ما تجده دون إضافة محارف اتجاه خفية إلى النص المعتمد.
```

#### P-TYPO-002 — تسلسل هرمي واضح

```text
راجع التسلسل الهرمي في كل شريحة: عنوان واحد واضح، ثم نص داعم أصغر بوضوح، ثم تفاصيل.
إن تساوى حجمان أو تنافسا فاقترح الفرق المناسب.
```

#### P-TYPO-003 — حجم العناوين

```text
كبّر عناوين الشرائح قليلًا حيث تسمح المساحة، دون أن ينزل أي نص تحت حد القراءة على الهاتف،
ودون أن ينتهي سطر بكلمة وحيدة.
```

#### P-TYPO-004 — تزويج الخطوط

```text
اقترح تزويجًا للخطوط من الخطوط المتاحة (Cairo وTajawal وAlmarai وReadex Pro):
خط للعناوين وخط للنص، لموضوع [TOPIC] وجمهور [AUDIENCE]، مع السبب،
ثم طبّقه وأعد التوزيع.
```

#### P-TYPO-005 — طول السطر

```text
بعض الأسطر طويلة. قسّم نصوص الشرائح أسطرًا قصيرة بنفسك (سطر لكل جملة أو نصف جملة)،
من سطرين إلى أربعة لكل شريحة.
```

#### P-TYPO-006 — كسر الأسطر وكلمة وحيدة

```text
افحص نهايات الأسطر: لا سطر ينتهي بكلمة وحيدة، ولا تُفصل كلمة عن صفتها أو حرف جرّ عن اسمه.
اقسم الأسطر يدويًا حيث يلزم.
```

#### P-TYPO-007 — عربي مع إنجليزي

```text
في النص كلمات إنجليزية وأسماء حسابات. تأكد أنها معزولة في مكانها الصحيح من الجملة العربية،
وأن علامات الترقيم بجانبها لا تقفز إلى الطرف الآخر من السطر.
إن كانت هويتي تمنع الإنجليزية فاقترح بديلًا عربيًا لكل كلمة إلا اسم الحساب.
```

#### P-TYPO-008 — الأرقام

```text
وحّد الأرقام في كل التصميم إلى [الأرقام الغربية 123 / الأرقام العربية ١٢٣]،
ولا تخلط النظامين في شريحة واحدة.
```

#### P-TYPO-009 — علامات الترقيم

```text
دقّق علامات الترقيم العربية: الفاصلة « ، » والفاصلة المنقوطة « ؛ » وعلامة الاستفهام « ؟ »،
وعلامات التنصيص « »، والنقطتين قبل الشرح. لا علامات إنجليزية في نص عربي.
```

#### P-TYPO-010 — الحروف المقطعة

```text
افحص كل الصادرات (PNG وPDF والفيديو) بحثًا عن حروف عربية غير متصلة أو كلمات معكوسة.
إن نُقل التصميم إلى Canva فاقرأ النص من هناك وقارنه بالمعتمد حرفًا حرفًا.
```

#### P-TYPO-011 — التوازن البصري

```text
راجع التوازن البصري في كل شريحة: المسافة بين العنوان والنص، والهامش من جهة القراءة،
والفراغ الأبيض. اقترح تعديلات موضعية فقط ولا تغيّر الأسلوب.
```

#### P-TYPO-012 — تدقيق لغوي كامل

```text
دقّق نصوص كل الشرائح لغويًا: الهمزات، والتاء المربوطة والهاء، والألف المقصورة والياء،
والتنوين في موضعه («يوميًا» لا «يومياً»)، والتشكيل حيث يمنع اللبس فقط.
اعرض الأخطاء في جدول قبل أن تصلحها.
```

## 19. تحسين المحتوى

**القاعدة الذهبية:** اطلب تعديل ما يلزم فقط، وقل «احتفظ بكل شيء آخر كما هو». هذا يحمي التصميم ويوفر التكلفة.

#### P-IMP-001 — حسّن الهوك

```text
احتفظ بكل شيء كما هو. حسّن الهوك فقط:
ضع النتيجة أو الرقم أولًا، واجعله 8 كلمات أو أقل، دون تغيير الفكرة.
اعطني 3 بدائل وحلّلها، ثم طبّق الأقوى.
```

#### P-IMP-002 — اختصر النص

```text
اختصر نصوص الشرائح بنسبة 30٪ تقريبًا دون حذف أي فكرة،
وابدأ بالشرائح التي تجاوزت حد الكلمات في الفحص.
```

#### P-IMP-003 — اجعله أكثر انتشارًا بلا مبالغة

```text
اجعل هذا المحتوى أقوى في الانتشار دون تهويل:
افتتاحية أوضح، ومعلومة محددة أبكر، وسطر قابل للاقتباس، وسؤال ختامي محدد.
لا تضف ادعاءً لا يسنده المحتوى.
```

#### P-IMP-004 — أكثر سلطة ومصداقية

```text
اجعل هذا المحتوى أكثر مصداقية:
استبدل العبارات العامة بأمثلة محددة، وافصل الحقائق عن الآراء صراحة،
واحذف كلمات مثل «الكل يعرف» و«مضمون» و«سر خطير».

[TEXT]
```

#### P-IMP-005 — خفّف العبارات المستهلكة

```text
اعثر في هذا النص على العبارات المستهلكة (مثل «في عالمنا المتسارع»، «لا يخفى على أحد»،
«اخرج من منطقة راحتك») واستبدلها بكلام مباشر ومحدد.

[TEXT]
```

#### P-IMP-006 — أزل الطابع الآلي

```text
هذا النص يبدو كأنه مكتوب آليًا. أعد صياغته بصوت إنسان يتحدث لصديق:
جمل متفاوتة الطول، وأمثلة من الحياة، ولا قوائم مثالية التناظر، ولا ختام وعظي.

[TEXT]
```

#### P-IMP-007 — أوضح

```text
بسّط هذا النص حتى يفهمه طالب في المرحلة الثانوية من أول قراءة:
جمل أقصر، ومصطلح واحد في كل جملة على الأكثر، ومثال لكل فكرة مجردة.

[TEXT]
```

#### P-IMP-008 — فضول أكثر

```text
زِد الفضول في هذا المحتوى دون أن يصبح طُعمًا:
اذكر النتيجة وأخّر السبب إلى الشريحة التالية، وأضف سؤالًا في نهاية شريحتين،
لكن قدّم في كل شريحة شيئًا ملموسًا.
```

#### P-IMP-009 — حكاية أفضل

```text
حسّن السرد في هذه القصة: ابدأ من لحظة التوتر، واحذف التمهيد،
واجعل لحظة الإدراك جملة واحدة واضحة، واختم بدرس لا يتجاوز سطرًا.

[TEXT]
```

#### P-IMP-010 — دعوة أفضل

```text
استبدل الدعوة الختامية العامة بدعوة محددة تناسب هدف المحتوى:
للنقاش سؤال برقم أو اختيار، وللحفظ موقف يُستعمل فيه المحتوى، وللمشاركة شخص محدد يُرسل إليه.
```

#### P-IMP-011 — عربية أبسط

```text
بسّط العربية في هذا النص: فصحى سهلة، بلا كلمات نادرة، وبلا تراكيب معقدة،
مع الحفاظ على صحة اللغة.

[TEXT]
```

#### P-IMP-012 — أكثر احترافية

```text
اجعل هذا النص أكثر احترافية لجمهور مهني:
لهجة رصينة، وأرقام وأمثلة من بيئة العمل، وبلا رموز تعبيرية ولا تعجب متكرر.

[TEXT]
```

## 24. التعديل دون هدم التصميم

**لماذا هذا القسم مهم:** إعادة الإنشاء الكاملة تهدم تصميمًا جيدًا وتكلّف استدعاءات أكثر. التعديل الموضعي يمسّ العنصر المقصود وحده، وكثير منه ينفذه الاستوديو محليًا دون أي توليد.

أوامر تُنفَّذ فورًا في شريط «عدّل بالمحادثة» أو في المحادثة:

| الأمر | ماذا يحدث |
|---|---|
| «كبّر العنوان الثاني قليلًا» | عنوان الشريحة 2 فقط |
| «صغّر النص في الشريحة الخامسة» | نص الشريحة 5 فقط |
| `غيّر العنوان الأول إلى "…*كلمة*…"` | نصك حرفيًا، والكلمة بين نجمتين تُظلَّل |
| «لوّن العنوان الأول بالأزرق» | بلون من هويتك |
| «اجعل العنوان الرابع أعرض» | وزن أثقل |
| «وسّط العنوان الثاني» | محاذاة في الوسط |
| «حرّك العنوان الأول للأعلى قليلًا» | تحريك بسيط |
| «أخفِ العدّاد» / «أخفِ دعوة السحب» | من كل الشرائح |
| «غيّر الخط إلى تجوّل» | مع إعادة التوزيع |
| «حوّله إلى مربع» / «حوّله إلى ستوري» | تغيير المقاس مع إعادة التوزيع |
| «اقفل العنوان» / «فك القفل» | يمنع تعديل العنصر أو يسمح به |
| «تراجع» | يلغي آخر تعديل |
| «اختصر النص في الشريحة الثالثة» | يكتب المساعد صياغة أقصر دون لمس أي رسم |
| «غيّر الجرافيك الرابع» | رسم جديد لهذا العنصر وحده |

## 25. الذاكرة والهوية

بصيرة تحفظ **هوياتك** (ألوان بأدوارها، وخطوط، وقيود، ونبرة) و**تفضيلاتك** بنطاقها (حساب، منصة، مقاس). التفضيل الذي تقوله صراحة يُطبَّق. أما السلوك المتكرر فيصبح **اقتراحًا** فقط حتى تؤكده، وطلبك الحالي يتقدم دائمًا.

#### P-MEM-001 — احفظ هويتي

```text
احفظ هوية جديدة باسم [BRAND]:
اللون الأساسي [HEX]، والخلفية [بيضاء/داكنة]، وخط Cairo للعناوين وTajawal للنص،
وأرقام غربية، وبلا [ألوان ممنوعة]، وبلا كلمات إنجليزية في التصميم إلا الحساب [HANDLE]،
وبلا صور أشخاص أو وجوه.
```

#### P-MEM-002 — تذكّر تفضيلًا

```text
تذكّر: في حساب [HANDLE] أريد دائمًا [PREFERENCE].
```

مثال:

```text
تذكّر: في حساب @kitabwbs أريد دائمًا خطًا أكبر قليلًا للنص على إنستغرام.
```

#### P-MEM-003 — لا تستعمل هذا مرة أخرى

```text
لا تستعمل [THING] في تصاميمي مرة أخرى، في كل حساباتي.
```

#### P-MEM-004 — ماذا تعرف عني؟

```text
ماذا تعرف عن ذوقي وهويتي؟ افصل ما قلته صراحة عما استنتجته من سلوكي،
واذكر نطاق كل تفضيل.
```

#### P-MEM-005 — الاقتراحات من سلوكي

```text
اعرض الاقتراحات التي لاحظتها من اختياراتي المتكررة، ولا تطبق أيًا منها قبل أن أوافق.
```

#### P-MEM-006 — رأيي في التصميم

```text
رأيي في هذا التصميم: [FEEDBACK]
سجّله، وطبّق ما يخص هذا التصميم فقط، ولا تجعله قاعدة عامة إلا إن قلت «دائمًا».
```

مثال:

```text
رأيي في هذا التصميم: أحب الجرافيك لكن الخط صغير. والأسلوب لا يناسب هذا الموضوع.
```

#### P-MEM-007 — اعتمد التصميم

```text
اعتمد هذا التصميم كنموذج معتمد لهوية [BRAND] لأعود إليه لاحقًا.
```

#### P-MEM-008 — استعمل ما نجح دون نسخ

```text
استخدم الأنماط التي نجحت سابقًا في حسابي، والتصاميم المعتمدة في مكتبتي،
لكن لا تنسخ أي تصميم سابق حرفيًا. قل لي ما أعدت استعماله وما هو جديد.
```

## 26. Canva

مهارة `canva-arabic` تبني التصميم في حسابك الحقيقي على Canva **كعناصر منفصلة قابلة للتعديل**، وتختار طريقًا تدعمه Canva فعلًا في جلستك: أدوات الموصل، أو ملف PowerPoint تستورده، أو Connect API بمفتاحك، أو خطوات يدوية. بعد البناء تقرأ النتيجة وتقارن كل حرف.
**حدود معلنة:** موصل Canva لا يلوّن كلمة داخل نص ولا يظللها، ولا يختار الخط.

#### P-CANVA-001 — صمم في Canva

```text
صمم هذا الكاروسيل في Canva كعناصر منفصلة قابلة للتعديل (لا صورة مسطحة)،
ثم اقرأ النتيجة وقارن كل نص بالمعتمد حرفًا حرفًا.
قل لي مستوى التحرير الذي وصل، والطريق المستعمل، ومعرّفات التصاميم.
```

#### P-CANVA-002 — ما الذي تدعمه Canva الآن؟

```text
ما القدرات التي تدعمها Canva في هذه الجلسة (النصوص، الخط، الحركة، المدة، التصدير)؟
اعرضها بحالتها: مدعوم، جزئي، غير مدعوم، لم يُتحقق.
```

#### P-CANVA-003 — عدّل في Canva دون إعادة البناء

```text
في تصميمي على Canva [DESIGN_ID]: كبّر عنوان الصفحة [N] قليلًا فقط،
دون إعادة إنشاء التصميم ودون توليد صور. اعرض الخطة قبل التنفيذ.
```

#### P-CANVA-004 — ملف PowerPoint لـCanva

```text
صدّر التصميم كملف PowerPoint قابل للتعديل لأستورده في Canva،
وقل لي ما يتغيّر في الطريق (مثل التظليل الذي يغطي السطر كله).
```

#### P-CANVA-005 — ريل في Canva

```text
ابنِ هذا الريل في Canva بمشاهد منفصلة ومدد وحركة،
ثم قل لي بصراحة ما ضُبط وما لم يُضبط، ولا تضف صوتًا.
```

#### P-CANVA-006 — تحقق بعد النقل

```text
قارن النصوص في تصميم Canva [DESIGN_ID] بالنص المعتمد:
الهمزات، والتاء المربوطة، والأرقام، والكلمات المعكوسة، والمحاذاة.
اعرض الفروق في جدول قبل أي إصلاح.
```

## 29. البرومبتات الشاملة (Master Prompts)

برومبت واحد يقوم بكل شيء. انسخه، واملأ المتغيرات، واحذف الأسطر التي لا تحتاجها.

#### P-MASTER-001 — كاروسيل Instagram الشامل

```text
المهمة: كاروسيل Instagram احترافي 4:5
الموضوع: [TOPIC]
الجمهور: [AUDIENCE] (إن تركته فحدده أنت واذكره)
الهدف: [GOAL]
النبرة: [TONE]
عدد الشرائح: [NUMBER_OF_SLIDES] (أو قرره أنت)
الأسلوب: [STYLE] (أو اختر أنسب أسلوب موجود)
الهوية: هويتي المحفوظة

1. اقترح 3 أغلفة واختر أقواها بالتحليل لا بالذوق.
2. فكرة واحدة لكل شريحة، وعنوان قصير، ونص من سطرين إلى أربعة، وكلمة مظللة واحدة.
3. عدد البنود يطابق وعد الغلاف، والخاتمة سؤال يحدد الإجابة أو دعوة حفظ.
4. صمّم وافحص وأصلح أخطاء الفحص.
5. حلّل لـInstagram، ونفّذ التوصيات المقيسة ذات الأولوية العالية فقط، وأعد التحليل.
6. سلّمني: ملف المحرر، والدرجة قبل وبعد مع الثقة، وكابشنًا قصيرًا، وقائمة قراراتك.
```

#### P-MASTER-002 — الريل الشامل

```text
المهمة: ريل 9:16 مدته [SECONDS] ثانية
الموضوع: [TOPIC]
الجمهور: [AUDIENCE]
البنية: [هوك قوي / قصة / قائمة / مشكلة وحل / خرافة وحقيقة]

1. اكتب 3 مشاهد أولى بديلة (7 كلمات أو أقل) واختر الأقوى بالتحليل.
2. 9 مشاهد على الأكثر، فكرة لكل مشهد، ومدة كل مشهد من نصه.
3. حلقة مفتوحة في البداية تُجاب صراحة قبل الدعوة.
4. نصي، بلا وجوه، بلا موسيقى، والحركة للعنصر كاملًا لا للحروف.
5. حلّل الريل لـInstagram وFacebook وأصلح أكبر ضعف.
6. سلّمني: جدول المشاهد (النص، المدة، الحركة)، والفيديو من المحرر إن كانت المدة 30 ثانية أو أقل،
   أو البناء في Canva إن كانت أطول.
```

#### P-MASTER-003 — X الشامل

```text
المهمة: محتوى X عن [TOPIC]
الصيغة: [منشور قصير / سلسلة من N / منشور طويل]
الجمهور: [AUDIENCE]
```

#### P-MASTER-004 — Facebook الشامل

## 30. وصفات عمل كاملة

كل وصفة خطوات متتابعة، ولكل خطوة برومبتها. نفّذها بالترتيب في المحادثة نفسها حتى تبني كل خطوة على ما قبلها.

### 30.1 وصفة كاروسيل عالي الجودة

#### P-RCP-CAR-1 — البحث

```text
الخطوة 1 (بحث): موضوعي [TOPIC] لجمهور [AUDIENCE].
اجمع 5 حقائق بمصادرها، و3 أخطاء شائعة، و3 أسئلة يسألها الجمهور.
افصل الحقائق عن الاستنتاجات والآراء. لا تصمم شيئًا بعد.
```

#### P-RCP-CAR-2 — اختيار الزاوية

```text
الخطوة 2 (الزاوية): من البحث اقترح 3 زوايا، لكل زاوية غلاف مقترح.
حلّل الأغلفة الثلاثة لـInstagram واختر الأقوى، واذكر السبب بالأرقام.
```

```text
الخطوة 3 (النص): اكتب نص كاروسيل من [NUMBER_OF_SLIDES] شرائح بالزاوية المختارة:
فكرة لكل شريحة، وعنوان قصير، وسطران إلى أربعة، وعدد بنود يطابق الغلاف،
وخاتمة بسؤال محدد. اعرض النص في جدول قبل التصميم.
```

#### P-RCP-CAR-4 — التصميم

```text
نوّع التكوين ولا تكرر النوع نفسه في شريحتين متتاليتين، ثم افحص الجودة وأصلح الأخطاء.
```

#### P-RCP-CAR-5 — تحليل الخوارزمية

```text
الخطوة 5 (التحليل): حلّل التصميم لـInstagram:
```

#### P-RCP-CAR-6 — المراجعة

## 31. المشاكل الشائعة وحلولها

| المشكلة | البرومبت |
|---|---|
| النص كثير | `P-FIX-001` |
| التصميم مزدحم | `P-FIX-002` |
| العربية غير مرتبة | `P-FIX-003` |
| الهوك ضعيف | `P-FIX-004` |
| التصميم جميل والمحتوى ضعيف | `P-FIX-005` |
| درجة الخوارزمية منخفضة | `P-FIX-006` |
| الكاروسيل طويل | `P-FIX-007` |
| الريل يفقد المشاهدين | `P-FIX-008` |
| الحروف مقطعة أو معكوسة في التصدير | `P-FIX-009` |
| تنبيه فيض النص (`layout.overflow`) | `P-FIX-010` |
| التصميم لا يشبه هويتي | `P-FIX-011` |
| الثقة منخفضة دائمًا | `P-FIX-012` |

#### P-FIX-001 — النص كثير

```text
النص كثير. لكل شريحة تجاوزت حد الكلمات في الفحص: اختصرها إلى الحد المقترح بالضبط،
أو قسّمها على شريحتين إن كانت تحمل فكرتين. لا تصغّر الخط.
```

#### P-FIX-002 — التصميم مزدحم

```text
التصميم مزدحم. احذف العناصر الزخرفية الزائدة، واجعل في كل شريحة عنصرًا بطلًا واحدًا،
واترك فراغًا أبيض حول العنوان. احتفظ بالنصوص كما هي.
```

#### P-FIX-003 — العربية غير مرتبة

```text
العربية غير مرتبة. دقّق الهمزات والتاء المربوطة والألف المقصورة والتنوين والترقيم،
ووحّد الأرقام، واقسم الأسطر يدويًا بلا كلمة وحيدة في آخر السطر. اعرض الأخطاء قبل الإصلاح.
```

#### P-FIX-004 — الهوك ضعيف

```text
الهوك ضعيف. حلّل أجزاءه (الطول، الفضول، التحديد، مخاطبة القارئ، ما على المحك)،
واكتب 5 بدائل تعالج الأضعف، وحلّلها، وطبّق الأقوى في الغلاف فقط.
```

#### P-FIX-005 — التصميم جميل والمحتوى ضعيف

```text
لا تغيّر التصميم. حسّن المحتوى فقط: معلومة محددة بدل العامة في كل شريحة،
ومثال ملموس، وأقوى فكرة في الشريحة الثانية، وخاتمة بسؤال محدد.
ضع النصوص الجديدة في العناصر نفسها.
```

#### P-FIX-006 — درجة الخوارزمية منخفضة

```text
درجة [PLATFORM] منخفضة. اعرض أكبر 3 أسباب خفضتها مع مصدرها،
ونفّذ فقط التوصيات المقيسة التي أثرها نقطتان أو أكثر، ثم أعد التحليل.
إن كانت الأسباب تقديرات قاعدية بلا تاريخ لحسابي فقل ذلك.
```

#### P-FIX-007 — الكاروسيل طويل

```text
الكاروسيل طويل. ادمج الشرائح القصيرة المتشابهة، واحذف ما لا يضيف فكرة جديدة،
حتى يصبح [N] شرائح، وحدّث عدد الغلاف إن كان يذكر البنود.
```

#### P-FIX-008 — الريل يفقد المشاهدين

```text
الريل ضعيف الاستبقاء. ضع الوعد في أول 3 ثوانٍ، واختصر المشهد الأول إلى 7 كلمات،
واحذف أضعف مشهدين، وأجب عن سؤال البداية قبل الدعوة. ثم حلّل قبل وبعد.
```

#### P-FIX-009 — حروف مقطعة أو معكوسة

```text
في التصدير حروف عربية مقطعة أو كلمات معكوسة. أعد التصدير من المحرر،
وافحص النص الظاهر مقابل المعتمد حرفًا حرفًا. إن نُقل إلى Canva فاقرأه من هناك وقارن.
لا تضف محارف اتجاه خفية إلى النص المعتمد لإصلاح المعاينة.
```

#### P-FIX-010 — تنبيه فيض النص

```text
ظهر تنبيه layout.overflow. اختصر النصوص التي ذكرها الفحص بالكميات التي اقترحها فقط،
ولا تطلب تصغير الخط تحت حد القراءة على الهاتف.
```

#### P-FIX-011 — لا يشبه هويتي

```text
التصميم لا يشبه هويتي. طبّق هويتي المحفوظة بالكامل (الألوان بأدوارها، والخطوط، والقيود)،
واعرض المخالفات التي وجدها فحص الهوية.
```

#### P-FIX-012 — الثقة منخفضة دائمًا

```text
الثقة في تحليلاتي منخفضة دائمًا. ما البيانات التي تنقص حسابي؟
كم منشورًا أستورد، ومن أي منصة وصيغة، وكيف أربط المنشورات بتصاميمها؟
```

## 32. أفضل الممارسات

- **البرومبت القصير يكفي** حين تريد نسخة أولى أو تثق بهويتك المحفوظة. ابدأ قصيرًا ثم عدّل.
- **البرومبت المفصل** حين يكون للمنشور هدف محدد (بيع، حملة، جمهور جديد) أو قيود لا تعرفها بصيرة.
- **اطلب نسخًا متعددة** للهوك والغلاف والدعوة فقط، لا للكاروسيل كله.
- **شغّل التحليل** بعد التصميم وقبل النشر، وبعد كل تعديل كبير. لا تشغّله بعد كل كلمة.
- **لا تبالغ في التحسين:** توصية أثرها أقل من نقطتين لا تستحق تغيير صوتك. الدرجة دليل لا حكم.
- **حين لا تكفي البيانات:** أقل من 8 منشورات في نمط معين لا تقول شيئًا. الثقة المنخفضة صادقة، فلا تعاملها كخطأ.
- **افصل الحقائق عن الآراء** في كل محتوى معلوماتي، ولا تنشر رقمًا بلا مصدر.
- **اربط كل منشور بتصميمه** بعد استيراد نتائجه، فيتعلم حسابك من خصائص التصميم نفسه.
- **عدّل موضعيًا** ولا تطلب إعادة الإنشاء إلا إن كان الاتجاه كله خطأ.

## 33. توفير التكلفة وعدد الرموز

**المبدأ:** القياس المحلي أولًا، والذكاء الاصطناعي الدلالي عند الحاجة فقط.

- الاستوديو والتحليل والتوصيات تعمل **محليًا بلا رموز**: عدّ الكلمات، والكثافة، وطول الجمل، والترقيم، والأرقام، والبنية، والدرجات.
- الحكم الدلالي (الفضول، الجِدّة، الفائدة) اختياري، ويُحفظ لكل محتوى فلا يُطلب مرتين.
- الطلب المطابق لطلب سابق يُعاد من الكاش دون توليد.
- التعديلات البسيطة (حجم، لون، تحريك، مقاس، خط) تُنفَّذ محليًا دون أي استدعاء.
- كل استدعاء للذكاء الاصطناعي مسجل في سجل التكلفة، ويُعرض عدد الرموز فقط إن أعلنه المزوّد.

**سيئ:**

```text
أعد إنشاء الكاروسيل بالكامل.
```

**أفضل:**

```text
احتفظ بكل شيء كما هو.
عدّل فقط Hook الشريحة الأولى.
```

#### P-COST-001 — تعديل محلي بلا توليد

```text
نفّذ هذا التعديل محليًا دون أي توليد أو إعادة كتابة: [CHANGE]
```

#### P-COST-002 — حلّل محليًا فقط

```text
حلّل هذا المحتوى بالقياس المحلي فقط، دون حكم دلالي بالذكاء الاصطناعي،
وقل لي أي الأجزاء كانت ستتحسن دقتها بالحكم الدلالي.
```

#### P-COST-003 — حكم دلالي مرة واحدة

```text
احكم دلاليًا على هذا المحتوى مرة واحدة واحفظ الحكم له،
ثم استعمل الحكم المحفوظ في كل تحليل لاحق للمحتوى نفسه.
```

#### P-COST-004 — نسخ متعددة لجزء واحد

```text
لا تكتب الكاروسيل من جديد. اكتب 3 بدائل لعنوان الشريحة [N] فقط، وحلّلها.
```

#### P-COST-005 — تقرير التكلفة

```text
أرني تقرير سجل التكلفة لهذه الجلسة: عدد استدعاءات الذكاء الاصطناعي بأنواعها،
ونتائج الكاش، والرموز والتكلفة إن كانت معلنة.
```

#### P-COST-006 — أعد الاستعمال قبل التوليد

```text
قبل أن تولّد أي رسم أو نص جديد: ابحث في مكتبتي عن تصميم أو رسم مناسب،
وأعد استعماله إن وجدته، وقل لي ماذا أعدت استعماله.
```

## 34. أوامر بصيرة للمتقدمين

أداة الأوامر `studio` (وفي المستودع أيضًا `basira` بالأوامر نفسها، وتقاريرها نصية افتراضيًا). كل الأوامر تطبع JSON، ومخزنها `~/.baseera` أو `BASEERA_HOME`.

| الأمر | ماذا يفعل |
|---|---|
| `studio init` | ينشئ المخزن |
| `studio intent "<طلب>"` | ما يطلبه الكلام: الصيغة، والعدد، والمقاس، والوجهة |
| `studio plan "<طلب>" --brand ID` | المسار (إعادة استعمال أو جديد)، والذاكرة، والكاش، وكلفة التوليد المتوقعة |
| `studio styles` / `studio compositions` | الأساليب الجاهزة / التكوينات وحقولها |
| `studio compose spec.json --out design.json --html design.html` | يصمّم من المواصفة ويكتب ملف المحرر |
| `studio check design.json` | الفحص: أخطاء وتحذيرات |
| `studio edit design.json "<أمر>" --page N` | تعديل بالمحادثة |
| `studio prompts design.json --out prompts.md` | Storyboard والنسخة الجاهزة وبرومبت لكل شريحة |
| `studio render design.json out.html` | ملف المحرر من تصميم موجود |
| `studio format design.json story` | تغيير المقاس |
| `studio library list` / `history ID` / `revert ID REV` / `remix ID` | المكتبة والنسخ |
| `studio memory show` / `remember KEY VALUE` / `suggestions` | الذاكرة |
| `studio brand preset kitabwbs` / `brand add BRAND.json` | الهويات |
| `studio canva caps` / `canva plan design.json` | قدرات Canva وخطة النقل |
| `studio ledger report` | سجل التكلفة |
| `studio backup FILE` / `restore FILE` | نسخة احتياطية كاملة |
| `basira analyze-post post.txt --platform x` | تحليل منشور |
| `basira analyze-carousel design.json --platform instagram` | تحليل كاروسيل أو تصميم |
| `basira analyze-reel plan.json` | تحليل ريل (مخطط أو مشاهد أو نص) |
| `basira analyze-content content.json --platform all` | تحليل محتوى بأي صيغة |
| `basira analytics import instagram insights.json` | استيراد نتائج (JSON أو CSV) |
| `basira analytics link POST_ID DESIGN_ID --platform instagram` | ربط منشور بتصميمه |
| `basira analytics profile` | خط الأساس والأنماط وأفضل النطاقات |
| `basira analytics fetch instagram` | جلب مباشر بمفاتيح من البيئة (`.env.example`) |
| `studio algorithm signals` / `sources` | الإشارات ومصادرها |

خيارات التحليل: `--account @حسابك` و`--lang ar|en` و`--caption نص` و`--format text|json` و`--save` و`--semantic-request` و`--semantic ملف.json`.

## 35. حدود صريحة وما هو قيد التطوير

| الموضوع | الحالة |
|---|---|
| النشر على المنصات والجدولة | غير موجود. أنت تنشر، وبصيرة تحلل قبل النشر وتتعلم بعده |
| جلب النتائج مباشرة من واجهات المنصات | موجود في أداة الأوامر بمفاتيحك في البيئة، ومختبر بطلبات محاكاة فقط. الطريق المجرّب: استيراد ملف |
| متتبع تجارب A/B حية | **قيد التطوير**. المقارنة قبل النشر متاحة |
| تصدير فيديو أطول من 30 ثانية من المحرر | **قيد التطوير**. Canva متاح للأطول |
| تحليل إطارات الفيديو والصوت | غير موجود. الريل يُحلل من نصه ومشاهده ومدده |
| منحنيات الاستبقاء الفعلية للفيديو | **قيد التطوير**. البنية جاهزة لاستقبالها |
| أساليب Doodle وAuthority وModern Arabic وLuxury Minimal | **قيد التطوير**. انظر الجدول في القسم 17 |
| التكوينات التعليمية الأربعة مع غير الأسلوب التعليمي | **قيد التطوير** |
| مقاس 1080×1440 | غير متاح بعد. المتاح 4:5 و1:1 و9:16 |
| التظليل في PowerPoint | يغطي السطر كله لا نصفه السفلي |
| موصل Canva | لا يلوّن كلمة داخل نص، ولا يظللها، ولا يختار الخط |
| فهم اللهجات في التحليل | محدود: قوائم الكلمات بالفصحى أولًا |
| المنشورات التأملية والأقوال | يقدّرها التحليل المحلي أقل من حقها. استعمل الحكم الدلالي (`P-ALG-008`) |
| عدد الرموز والتكلفة | يُعرضان فقط إن أعلنهما المزوّد |
