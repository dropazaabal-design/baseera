# بصيرة — ورقة الاستعمال السريع

صفحة واحدة لأكثر ما تحتاجه يوميًا. التفاصيل وكل البرومبتات (أكثر من 350) في [الدليل الكامل](BASIRA-GUIDE-AR.md) و[ملفه PDF](BASIRA-GUIDE-AR.pdf)، ومقسّمة حسب الموضوع في [مكتبة البرومبتات](prompts/README.md).

**القاعدة:** استبدل ما بين القوسين المربعين بكلامك، واحذف سطر أي متغير لا تعرف قيمته.

## 1. الدورة الكاملة في خمس رسائل

```text
صمم لي كاروسيل إنستغرام من [NUMBER_OF_SLIDES] شرائح عن: [TOPIC]
```

```text
حلل هذا الكاروسيل قبل النشر على Instagram وX وFacebook.
أعطني درجة كل منصة مع أسبابها ودرجة الثقة، ثم أهم ثلاثة تعديلات فقط.
```

```text
حلل هذا الكاروسيل لـ[PLATFORM].
نفّذ فقط التوصيات ذات الأولوية العالية المرتبطة بخاصية مقيسة،
ثم أعد التحليل وأعطني الدرجة قبل وبعد.
```

```text
لا تعِد إنشاء التصميم. احتفظ بالتوزيع والخطوط والألوان والمسافات.
غيّر فقط: [CHANGE]
```

```text
سلّمني ملف المحرر، وكل الشرائح ZIP بترتيب النشر، وكابشنًا قصيرًا ينتهي بسؤال محدد.
```

الرموز في الدليل: `P-START-001` و`P-START-003` و`P-ALG-002` و`P-EDIT-001` و`P-START-005`.

## 3. ذكاء المنصات في أربع خطوات

1. **قبل النشر:** حلّل لكل منصة (`P-ALG-001`)، واطلب الأسباب إن لم تفهم الدرجة (`P-ALG-003`).
2. **أصلح بقدر:** نفّذ التوصيات المقيسة فقط وأعد التحليل (`P-ALG-002`)، ولا تبالغ في التحسين (`P-ALG-013`).
3. **قبل الاختيار:** قارن نسختين أو هوكين (`P-ALG-005`، `P-AB-001`).
4. **بعد النشر:** استورد نتائجك (`P-ACC-001`) واربط المنشور بتصميمه (`P-ACC-004`)، فتصبح التوصيات التالية مبنية على حسابك لا على القواعد العامة.

الدرجة **ملاءمة** للمنصة لا توقّع للانتشار. ومعها دائمًا درجة ثقة: منخفضة حين لا يوجد سجل لحسابك، وترتفع مع كل منشور تستورده.

## 6. للتوفير

```text
نفّذ هذا التعديل محليًا دون أي توليد أو إعادة كتابة: [CHANGE]
```

التعديل والفحص والتحليل المحلي بلا رموز (tokens). الحكم الدلالي بالذكاء الاصطناعي اختياري، ويُحفظ فلا يُدفع مرتين لنفس النص (`P-COST-001` إلى `P-COST-006`).

## 7. أوامر للمتقدمين

| الأمر | ماذا يفعل |
|---|---|
| `basira analyze-carousel design.json --platform instagram` | تحليل كاروسيل أو تصميم |
| `basira analyze-post post.txt --platform x` | تحليل منشور |
| `basira analytics import instagram insights.json` | استيراد نتائج (JSON أو CSV) |
| `basira analytics link POST_ID DESIGN_ID --platform instagram` | ربط منشور بتصميمه |
| `basira analytics profile` | خط الأساس والأنماط وأفضل النطاقات |
| `studio library list` / `revert ID REV` | المكتبة والنسخ |

## 8. ما ليس موجودًا بعد

النشر والجدولة على المنصات غير موجودين. **قيد التطوير:** متتبع تجارب A/B حية، وتصدير فيديو أطول من 30 ثانية من المحرر، ومنحنيات الاستبقاء الفعلية للفيديو، وأساليب Doodle وAuthority وModern Arabic وLuxury Minimal. القائمة الكاملة في القسم 35 من الدليل.
